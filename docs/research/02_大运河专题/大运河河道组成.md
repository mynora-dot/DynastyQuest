# 大运河河道组成

> **核心结论（务必贯彻）**：隋朝大运河**不是一次性从零开凿的工程**，而是"**新开若干段 + 疏浚改造旧渠 + 串联天然河流湖泊**"的系统工程。其中广通渠、永济渠为新开为主，通济渠、邗沟、江南河大量利用先秦以来的鸿沟—汴渠水系、邗沟旧道与六朝江南运道。游戏中若把运河表现为"一锹一锹挖出来的直线水渠"，即为史实错误。
>
> 可信度标记：A 可靠 / B 细节有争议 / C 学界异说 / D 游戏推演。

## 〇、总体结构

隋大运河以**洛阳（东都）为中心**，呈"人"字形放射：

```
                涿郡（今北京西南）
                     ▲
                     │ 永济渠（608，引沁水北通涿郡）
                     │
   大兴城 ──广通渠──▶ 洛阳 ◀──黄河──板渚
   （584，300余里）      │
                        │ 通济渠（605，引谷洛入河，自板渚引河入淮）
                        ▼
                      淮水（泗州）
                        │
                        │ 邗沟／山阳渎（587 旧开，605 重开）
                        ▼
                      江都（扬州）──长江──京口
                                          │
                                          │ 江南河（610，800余里）
                                          ▼
                                        余杭（杭州）
```

四点必须记住：
1. **广通渠是东西向**，解决关中漕运，不经洛阳；
2. **通济渠是西北—东南向**，洛阳—淮河；
3. **永济渠是西南—东北向**，黄河—涿郡，与通济渠在黄河两岸分岔；
4. **江南河**在长江以南，与邗沟隔江相接。

因此"从杭州坐船一路直达北京"在隋代是**理论上可通、实际上需多次转运过闸过堰**的路线，绝非无障碍直达。参见《大运河运输体系》。

## 一、广通渠

| 项目 | 内容 |
|---|---|
| 开凿时间 | 隋文帝开皇四年（584） |
| 主持者 | 宇文恺率水工勘测设计（《隋书·食货志》）；另有郭衍开"富民渠"事，属另一工程，勿混 |
| 起点 | 大兴城（今西安）附近的渭水 |
| 终点 | 潼关附近入黄河（一说至华阴永丰仓一带） |
| 全长 | 三百余里（《隋书·食货志》） |
| 性质 | **新开为主**，线路大体沿汉代漕渠故道 |
| 连接河流 | 渭水—黄河 |
| 主要功能 | 把关东、河东漕粮从黄河转入关中，避开渭水下游"三门砥柱"与渭口泥沙淤浅 |
| 史料 | 《隋书》卷二四《食货志》；《隋书》卷六一《郭衍传》；水利部《水利百科·漕渠》条 |

**路线**：自大兴城北/西北引渭水，傍渭水南岸东行，经今临潼、渭南、华州，至潼关附近入河。水利部《水利百科》明确："隋开皇四年（584年），为同一目的，隋文帝下令开广通渠，也引渭水自大兴城北，东至潼关300余里达黄河，其线路与汉漕渠基本相同。"

**唐代沿用与改造**：唐天宝元年（742）重修，改在咸阳西筑兴城堰分水，东至潼关西永丰仓合渭水入河（水利部《水利百科》）。**这是唐代工程，不能写进隋代章节。**

**争议（C）**：
- 广通渠是否全程新开，还是基本沿汉漕渠疏浚？学界多认为"因汉故渠而修"，但《隋书》用"凿渠"字样。
- 渠首具体位置（大兴城西北 vs 城北）各家复原不同。
- 是否可全年通航：渭水流量季节变化大，冬季与枯水期通航能力存疑，标 C。

**游戏转化**：可作为"关中漕运"支线场景——渭水边的渠首闸口、转运仓、纤夫道。但第一章（洛阳—江都）不必展开。

## 二、通济渠（唐称广济渠，宋称汴河）

| 项目 | 内容 |
|---|---|
| 开凿时间 | 隋炀帝大业元年（605）三月 |
| 用工 | 发河南、淮北诸郡男女百余万（《隋书·炀帝纪上》） |
| 起点 | 洛阳西苑，引谷水、洛水入黄河 |
| 中段 | 自黄河**板渚**（今河南荥阳汜水镇东北）引河水，东行与古汴渠故道相接 |
| 转折 | 至汴州（今开封）以东**改道向东南**，不再走古汴渠向徐州入泗的旧线 |
| 终点 | 泗州（今江苏盱眙淮河北岸附近）入淮河 |
| 全长 | 约千余里（各家复原 1000—1300 里不等，标 B） |
| 宽度 | 渠广四十步；两岸筑御道，植柳（《隋书·炀帝纪上》所载"广四十步"） |
| 性质 | **新开 + 利用古汴渠/睢水故道**的混合工程 |

**途经地区（据山东省水利厅《汴渠》条）**：洛阳—荥阳板渚—开封—杞县—商丘（宋州）—夏邑—永城—宿州—灵璧—泗县—泗洪—泗州入淮。

**连接河流**：谷水、洛水 → 黄河 → 汴渠故道 → 睢水水系 → 淮河。

**连接城市**：洛阳（东都）、汴州、宋州、宿州（唐置，隋为符离）、泗州。

**运输功能**：江淮漕粮北上的主通道；炀帝三下江都即由此道。唐代每年经此漕运粮食常达四百万石（山东省水利厅《汴渠》条引述，属唐宋通例，非隋代定额）。

**与其它河道关系**：西端接洛阳城西苑水系与洛水；东端在泗州与淮河、邗沟相接，构成"洛阳—淮—江"纵贯线。

**史料**：《隋书》卷三《炀帝纪上》；《隋书》卷二四《食货志》；《资治通鉴》卷一八〇；《通典》卷一〇〈食货典·漕运〉。

**争议（C）**：
1. **是否全为新开**：传统教科书说"开凿通济渠"，但水利史界普遍认为开封以东大量利用睢水、蕲水故道，属"因旧道而浚广之"。
2. **入淮口位置**：一说泗州（盱眙对岸），一说在青口/老子山一带，考古与文献互有出入。
3. **"广四十步"的步制换算**：隋一步约 1.47 米，四十步约 59 米，但河道宽度随地形变化，不能视为全线标准断面。
4. **通济渠与古汴渠的关系**：唐宋人已多混称"汴河"，需注意隋唐之际的"汴"多指通济渠新线。

**游戏转化**：第一章主舞台的"水路大动脉"。可做：汴口引水闸、柳堤御道、纤夫号子、漕船队列、汴州码头夜泊。

## 三、邗沟（山阳渎）

| 项目 | 内容 |
|---|---|
| 前身 | 春秋吴王夫差开邗沟（公元前 486 年），沟通江淮 |
| 隋第一次 | 开皇七年（587）四月，"于扬州开山阳渎以通运"（《隋书·高祖纪上》） |
| 隋第二次 | 大业元年（605），"发淮南民十余万开邗沟，自山阳至扬子入江"（《隋书·炀帝纪上》） |
| 起点 | 山阳（今江苏淮安） |
| 终点 | 扬子（今扬州南，长江北岸） |
| 性质 | **疏浚旧道 + 局部改线**，非全新开凿 |
| 连接 | 淮河—射阳湖—樊梁湖—博支湖—长江 |
| 史料 | 《隋书》卷一《高祖纪上》、卷三《炀帝纪上》；《资治通鉴》卷一八一 |

**工程要点**：邗沟穿越江淮之间的一系列湖泊洼地，需"穿渠"连接湖面，故沿线多堰埭、斗门。隋代是否已有完整船闸（复闸）**没有史料支持**——复闸（如真州闸、瓜洲闸）是唐宋以后的技术，切勿提前使用（C 级警示）。

**争议**：
- 开皇七年"山阳渎"与炀帝"邗沟"是否同一条线：多数学者认为山阳渎即邗沟故道的疏浚，炀帝时又加拓宽取直。
- "自山阳至扬子入江"的"扬子"具体位置（今扬州南扬子桥一带 vs 仪征附近）有异说。

**游戏转化**：第一章后段场景。可做：湖上风浪、堰埭过船、纤夫拉纤、江都城门与码头。

## 四、永济渠

| 项目 | 内容 |
|---|---|
| 开凿时间 | 隋炀帝大业四年（608）正月（一说正月乙巳诏） |
| 用工 | 诏发河北诸郡男女百余万（《隋书·炀帝纪上》） |
| 起点 | 黄河/沁水交汇处（今河南武陟、修武一带），"引沁水南达于河" |
| 终点 | 涿郡（今北京西南，隋涿郡治蓟县） |
| 全长 | "二千余里"为通行估算（B）。《隋书》《通鉴》原文只记"北通涿郡"，未给总里程 |
| 性质 | **新开为主，部分利用曹操白沟、清河等旧渠** |
| 连接 | 沁水—黄河—海河水系（清水/淇水、漳水、滹沱、拒马河等）—涿郡 |
| 功能 | 转输河北及东北军粮，为征高句丽服务；后为唐代河北漕运干线 |
| 史料 | 《隋书》卷三《炀帝纪上》；《资治通鉴》卷一八一；海河水利委员会《治水历史·永济渠》 |

**路线（通行复原，B）**：武陟—新乡—汲县—滑县—内黄—魏县—大名—馆陶—临清—武城—德州—东光—沧州—静海—信安—涿郡。即大体沿今卫河—南运河—北运河一线。

**争议（C）**：
1. 永济渠北段是否借永定河（桑干河）水道入涿郡，还是另开新渠，学界有争论。
2. 渠首"引沁水"的具体分水口位置（沁水入黄河口附近）各家复原不同。
3. 永济渠是否通航至涿郡城下，抑或止于城南，尚有讨论。
4. "二千余里"的数字并非《隋书》《通鉴》原文，而是据复原路线估算（今测约 1900—2300 里），引用时须注明为"今人估算"。

**游戏转化**：适合第二、三章（隋末、唐初）的河北场景。第一章可作为"远征辽东的军粮运输"背景提及。

## 五、江南河

| 项目 | 内容 |
|---|---|
| 开凿时间 | 隋炀帝大业六年（610）十二月（《资治通鉴》卷一八一） |
| 起点 | 京口（今江苏镇江） |
| 终点 | 余杭（今浙江杭州） |
| 全长 | 八百余里（《资治通鉴》卷一八一） |
| 宽度 | 广十余丈（同上） |
| 性质 | **疏浚、拓宽六朝江南运道**（六朝已有破岗渎、上容渎等运道基础） |
| 连接 | 长江—太湖流域—钱塘江 |
| 史料 | 《资治通鉴》卷一八一；《隋书》卷三《炀帝纪上》（系年较简） |

**争议（B/C）**：
- 开凿年代：《通鉴》系于大业六年，但《隋书》本纪记载简略，部分学者认为工程分阶段进行。
- 是否全线新开：学界普遍认为利用了六朝以来的江南水道，隋代主要是浚广、取直。
- 具体线路：京口—丹阳—常州—无锡—苏州—嘉兴—杭州，与今江南运河大体重合，但局部（如苏州段）古今河道有摆动。

**游戏转化**：适合后期"江南"章节。第一章可作为"运河最南端"的知识卡与传闻。

## 六、其它相关河道与既有水运线路

| 名称 | 时代 | 关系 | 说明 |
|---|---|---|---|
| 鸿沟 | 战国魏 | 通济渠前身之一 | 荥阳引黄河水东南流，连接济、汝、淮、泗 |
| 汴渠（古汴河） | 汉—南北朝 | 通济渠利用的旧道 | 汉王景治汴；隋改道后"汴"名沿用，实为新线 |
| 山阳渎 | 隋开皇七年 | 邗沟疏浚段 | 见上 |
| 白沟、平虏渠、泉州渠 | 东汉末曹操 | 永济渠北段前身 | 河北平原上的旧运渠 |
| 破岗渎、上容渎 | 六朝吴、梁 | 江南河前身 | 沟通建康与太湖流域 |
| 灵渠 | 秦 | 与隋运河无直接关系 | 常被误列入"隋唐运河"，实为岭南灵渠，勿混 |
| 三门砥柱漕道 | 汉—唐 | 关中漕运瓶颈 | 唐开元末开"开元新河"（三门运渠），仍险 |

> **常见错误**：把秦代灵渠、东汉白沟、六朝破岗渎统统算作"隋朝大运河"。正确表述是：隋朝"整合"了这些前代水道，新开约占总里程的一半左右（比例各家估算不同，标 C）。

## 八、本章（第一章）使用建议

1. **主路线**：洛阳 → 通济渠 → 汴州 → 宋州 → 泗州 → 邗沟 → 楚州 → 江都。这是隋大业年间最成熟、史料最集中的一段。
2. **不要**让玩家在第一章"从洛阳直达涿郡"或"直达余杭"：永济渠 608 年才开，江南河 610 年才开，若第一章设定在 605—607 年，则这两段尚未存在。**这是时间一致性硬约束。**
3. 场景中的水工设施以**堰、埭、斗门、土堤、木岸**为主，**不要**出现宋代式的复闸、船闸、澳闸。
