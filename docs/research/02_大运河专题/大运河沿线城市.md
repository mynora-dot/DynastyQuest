# 大运河沿线城市

> 统一格式：隋唐名称 / 今地 / 沿革 / 行政地位 / 规模与布局 / 经济 / 交通 / 建筑 / 人物 / 与运河关系 / 事件 / 游戏场景 / 任务。
> 标记：A 可靠 / B 有争议 / C 异说 / D 游戏推演。**今地对应为"大致方位"，古城址与今城区往往不重合，详见《03_历史地理/历史地名对照表》。**

---

## 一、总览：运河城市带

```
大兴城（长安）
   │ 广通渠（584）
   ▼
潼关 ── 黄河 ── 洛阳（东都，605）
                    │ 通济渠（605）
                    ▼
          汴州 ─ 宋州 ─ 泗州 ── 淮河
                                  │ 邗沟（587/605）
                                  ▼
                          楚州 ─ 江都（扬州）
                                  │ 长江
                                  ▼
                          京口 ─ 江南河（610）─ 余杭

涿郡（蓟）◀── 永济渠（608）── 黄河/沁水口
```

**两类城市**：
1. **因运河而兴**：汴州、宋州、楚州、泗州（中转、仓储、商贸）；
2. **因政治而设**：大兴城、洛阳、江都（都城/陪都/行都）。

## 二、大兴城（长安）

| 项目 | 内容 |
|---|---|
| 隋名 | 大兴城（隋文帝封大兴公，故名） |
| 唐名 | 长安（618 年改） |
| 今地 | 陕西省西安市市区（隋唐长安城遗址） |
| 行政地位 | 隋京师；唐上都/西京，京兆府治 |
| 始建 | 开皇二年（582）六月诏营，开皇三年（583）迁入（A） |
| 规划者 | 宇文恺（设计）、高颎（总监） |
| 面积 | 约 84 平方公里（唐长安，考古实测，A） |
| 布局 | 宫城—皇城—外郭城；棋盘格；108 坊 + 东西两市（坊数有异说，B） |
| 中轴 | 朱雀大街（宽度各家实测 127—150 米不等，B/C） |
| 经济 | 官营手工业、东西市商业、邸店、胡商 |
| 交通 | 广通渠通黄河；陆路驿道四通 |
| 建筑 | 太极宫、大明宫（634 始建）、兴庆宫（玄宗）、大雁塔（652）、曲江池 |
| 人物 | 宇文恺、杨坚、李世民、玄奘、李白、杜甫 |
| 与运河 | 广通渠的西端起点，漕粮终点 |
| 事件 | 581 建隋、618 建唐、626 玄武门、649 太宗崩、690 武周代唐、904 废毁 |
| 游戏场景 | 明德门、朱雀大街、西市、东市、曲江、大雁塔、坊内民居 |
| 任务 | 坊门夜禁、西市胡商、科举放榜、漕粮入仓 |

> **注意**：大兴城 ≠ 唐长安城。城址相同，但**宫城名称、坊名、市场、宫殿**在唐代有大量增改（大明宫、兴庆宫均为唐代新建）。第一章（隋）只能用**大兴城**的名称与隋代建筑。

## 三、洛阳（东都）

| 项目 | 内容 |
|---|---|
| 隋名 | 东京/东都（605 年营建） |
| 唐名 | 东都（657 年改洛阳宫为东都）、神都（武则天，684/690） |
| 今地 | 河南省洛阳市（隋唐洛阳城遗址） |
| 行政地位 | 隋东都；唐东都；武周神都（实际首都） |
| 始建 | 大业元年（605）三月诏营，宇文恺主持（A） |
| 面积 | 约 47 平方公里（考古推算，B） |
| 布局 | 宫城（紫微城）在西北隅、皇城（太微城）其南、郭城周围；洛水穿城；里坊 100 余坊（隋 103、唐 109 等异说，C） |
| 市场 | 南市、北市、西市（三市，唐）；隋有丰都市、大同市、通远市 |
| 水系 | 洛水、伊水、谷水；通济渠起点（西苑） |
| 仓储 | 子罗仓（城内）、回洛仓（城北）、洛口仓（城东巩义） |
| 建筑 | 乾阳殿、明堂（武周）、上阳宫（唐）、天津桥、含嘉城 |
| 人物 | 杨广、宇文恺、武则天、狄仁杰、安禄山（称帝于此） |
| 与运河 | **运河体系的中心**，通济渠西端 |
| 事件 | 605 营东都、613 杨玄感围城、618 王世充据守、690 武则天称帝、756 安禄山称帝、762 史朝义败走 |
| 游戏场景 | 天津桥、南市、洛水码头、西苑、宫城、里坊 |
| 任务 | 漕粮转运、市场纠纷、宫城密信、洛水救援 |

> **时代错置警示**：
> - 605 年前无"东都"，只能说"洛阳"；
> - 隋代市场是丰都、大同、通远三市，**不是**唐后期的南市、北市、西市；
> - 含嘉仓为唐仓，隋代应写子罗仓、回洛仓、洛口仓；
> - 明堂为武周建筑（688 年拆乾元殿营建），605 年不存在。

## 四、汴州

| 项目 | 内容 |
|---|---|
| 隋名 | 汴州（治浚仪） |
| 唐名 | 汴州（天宝元年—乾元元年改陈留郡） |
| 今地 | 河南省开封市 |
| 行政地位 | 州治；唐宣武军节度使驻地（781 后） |
| 沿革 | 北周置汴州；隋因通济渠而兴；唐为漕运咽喉 |
| 规模 | 州城，面积小于两京；城址屡被黄河泛滥掩埋（B） |
| 经济 | 漕运中转、邸店、商税、造船 |
| 交通 | 通济渠穿城/傍城；陆路通洛阳、宋州 |
| 建筑 | 州衙、仓廒、码头、城门 |
| 人物 | 唐代李勉、董晋等；隋代人物记载少（C） |
| 与运河 | 通济渠中段最重要的节点，江淮粮船必经 |
| 事件 | 隋末王世充与李密争夺；唐建中后为宣武军镇 |
| 游戏场景 | 汴河码头、州桥、仓场、邸店街 |
| 任务 | 粮船查验、码头斗殴、货栈失窃、河堤抢险 |

> 汴州城址因黄河泥沙淤积，**隋唐汴州城深埋于今开封地下**，考古发掘受限（B）。游戏中可依文献与少量考古复原，不要直接套用北宋东京城布局。

## 十一、城市带的空间逻辑（策划用）

1. **距离感**：洛阳—汴州约 400 里，汴州—宋州约 300 里，宋州—泗州约 400 里，泗州—楚州约 200 里，楚州—江都约 300 里（均为约数，B）。游戏可据此设定"每城之间 1—2 个驿站、1 天路程"。
2. **地形变化**：洛阳盆地 → 黄淮平原 → 江淮湖沼 → 长江三角洲。地图配色与障碍物应随之变化。
3. **城市等级**：都城（大兴、洛阳）> 行都（江都）> 州治（汴、宋、泗、楚）> 县城 > 镇/草市。
4. **水路优先**：运河城市的主街多与河道平行，码头是城市"第二中心"。
