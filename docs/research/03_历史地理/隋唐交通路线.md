## 一、驿传制度：先说清"驿"与"传"

游戏里最常见的错误，是把"驿"当成客栈、把"30 里一驿"当成隋制。两者都要纠正。

| 项目 | 内容 | 时代性警示 | 出处与可信度 |
|---|---|---|---|
| **传** | 官府设置的车马机构，供官员乘用、运送物资，凭"传符"发用 | 秦汉已有，唐仍置，中唐后渐并入驿 | 《唐六典》卷五（B） |
| **驿** | 设于驿路上的站点，备马匹、驴、船，供传递文书与官员中途换乘 | 隋已有驿，唐制大备 | 《唐六典》卷五（B） |
| **驿传合一** | 唐前期"传驿"并称，中唐以后"驿"兼"传"之职，形成后世"驿站"概念 | 不可把晚唐"驿站"套到隋代 | B |
| **30 里一驿** | 唐制"凡三十里一驿"，路非要冲或水陆相兼者可因地制宜 | **这是唐制，不能套到隋及更早** | 《唐六典》卷五（A） |
| **驿数** | 《唐六典》载全国驿合计一千六百余所（陆驿、水驿、水陆相兼三类） | 具体分类数字有异说 | 《唐六典》卷五（B） |
| **水驿** | 沿江、运河设水驿，备船；行程按水程计，不以 30 里为限 | 江南河、邗沟沿线多水驿 | B |
| **过所** | 过关津须持官府所发"过所"（通行凭证），私度有罪 | 隋唐皆然，是重要的关卡玩法依据 | 《唐律疏议》卷八《卫禁》（A） |
| **驿马与传马** | 按驿站等级配马，紧急文书可"驰驿"昼夜兼行 | 日行里数因等级而异，不可写死 | B |

> **给策划的一句话**：隋代说"驿"可以，说"30 里一驿"不行；唐代说"30 里一驿"可以，但要说清那是制度规定而非处处如此。

## 二、以两京为中心的驿路网

```
                    代州─雁门──┐
                         │      │
        灵州──原州──邠州──长安──华州──潼关──陕州──洛阳──汴州──宋州
              │           │                          │        │
              │           └──凤翔──散关──兴元──剑门──成都      ├──魏州──幽州
              │                                              │
            凉州──甘州──肃州──瓜州──沙州──伊州──西州──庭州    └──襄阳──荆州──潭州
```

长安与洛阳是两个枢纽，但功能不同：**长安的驿路是"放射状"，洛阳的驿路是"十字状"**。长安要控制关陇、巴蜀、河东、朔方四个方向；洛阳要控住运河与南北陆路。

## 三、九条干线

### 3.1 两京道（长安—洛阳）

| 项目 | 内容 |
|---|---|
| 走向 | 长安—华州—潼关—陕州—硖石—新安—洛阳 |
| 里程 | 约八百余里（B；通行估算） |
| 地形 | 关中平原—崤函山地—伊洛平原，中间最险为崤山段 |
| 功能 | 皇帝巡幸、公文传递、漕粮陆运转般、使节往来 |
| 驿站 | 长乐驿（长安东）、马嵬驿（在长安西，属西出线，非本道）、稠桑驿等；**多数驿名待考** |
| 时代变化 | 唐前期极盛；安史之乱后潼关—陕州段屡为战场，驿路时断 |
| 史料 | 《旧唐书》卷三八《地理志一》；《资治通鉴》卷二一八（马嵬驿在兴平西，属西线）（A／B） |

> 注意：**马嵬驿不在两京道上**，它在长安以西的兴平。写"玄宗奔蜀"路线时，是长安—马嵬—扶风—散关—剑门—成都，与两京道相反方向。

### 3.2 长安—太原—幽州道

| 项目 | 内容 |
|---|---|
| 走向 | 长安—同州—蒲津渡—蒲州—绛州—太原—忻州—代州；或太原—井陉—恒州—易州—幽州 |
| 里程 | 待考（史料只给分段日程，未给全程） |
| 功能 | 控河东、援河北；唐初御突厥、唐末藩镇命脉 |
| 关键节点 | 蒲津浮桥、太原（北都）、井陉关、飞狐陉 |
| 时代变化 | 617 年李渊自晋阳南下，走的正是这条线的南段 |
| 史料 | 《旧唐书》卷一《高祖纪》（A） |

### 3.3 长安—凉州—西域道（丝绸之路东段）

| 项目 | 内容 |
|---|---|
| 走向（北道） | 长安—邠州—泾州—原州—会州—凉州 |
| 走向（南道） | 长安—凤翔—秦州—渭州—兰州—凉州 |
| 西段 | 凉州—甘州—肃州—瓜州—沙州—玉门关／阳关—伊州—西州—龟兹 |
| 里程 | 长安—凉州约二千里（B） |
| 功能 | 军政传递、商队、僧侣、使节；唐前期丝路最盛 |
| 关键节点 | 萧关、玉门关、莫贺延碛、伊吾、高昌 |
| 时代变化 | 贞观十四年（640）平高昌置西州后全线畅通；安史之乱后吐蕃切断陇右，此道中断 |
| 史料 | 《旧唐书》卷四〇《地理志三》、卷一九八《西戎传》（A） |

> 玄奘西行（贞观初）走的就是这条线的南道—莫贺延碛—伊吾—高昌，可与《大慈恩寺三藏法师传》互证（B，**该书未逐页核对**）。

### 3.4 洛阳—汴州—扬州—杭州（运河线）

| 项目 | 内容 |
|---|---|
| 走向 | 洛阳—汴州—宋州—宿州—泗州—楚州—扬州—润州—常州—苏州—杭州 |
| 分段里程 | 通济渠千余里（B）；邗沟三百余里（B）；江南河八百余里（A，《资治通鉴》卷一八一） |
| 功能 | 江淮漕粮北运、盐运、商旅、炀帝南巡 |
| 关键节点 | 汴口、泗州入淮口、山阳、扬子、京口 |
| 时代变化 | 605 通济渠、610 江南河成，全线贯通；安史之乱后运河为唐廷命脉 |
| 史料 | 《隋书》卷三《炀帝纪上》；《资治通鉴》卷一八一；《通典》卷一〇（A） |

> 运河线的"里程"不能简单相加当直线距离：通济渠是斜向东南，邗沟是南北向，江南河又转东西，三段折线相加远大于两京直线距离。参见《大运河河道组成》第七节。
