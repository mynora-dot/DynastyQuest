# 太原（晋阳）

> 晋阳是李唐的龙兴之地，也是唐代的北都、北京。本档与《02_大运河专题》无直接交集，但与《范阳.md》《潼关.md》共同构成"唐初军事地理"三角。标记：**A** 正史或考古实测可互证；**B** 有据而细节有异说；**C** 异说并列；**D** 游戏推演。

**一句话定位**：晋阳是"表里山河"的产物——西有吕梁、东有太行、北有雁门、南有汾河谷地，进可出井陉争河北，退可闭关自守。**李渊选在这里起兵，不是偶然。**

## 三、地理环境

| 要素 | 内容 | 意义 |
|---|---|---|
| 盆地 | 太原盆地，汾河纵贯 | 农业与人口基础 |
| 河流 | 汾河；晋水（难老泉等），灌溉晋祠一带 | 城市水源与园林 |
| 山脉 | 西吕梁，东太行，北系舟、雁门 | "表里山河"，易守难攻 |
| 关隘 | 北出雁门、东出井陉、东南出娘子关（苇泽关） | 三个方向决定太原的攻守 |
| 周边 | 忻州、代州（北）、汾州（南）、潞州（东南）、恒州/镇州（东出井陉） | 河东与河北的联结 |
| 交通 | 汾河谷道南北贯通；井陉道东出河北 | 兵家必争 |

**军事地理要点**：太原是河北与关中之间的"第三极"。从太原东出井陉，可直插恒州、赵州，威胁范阳的后路——**757 年郭子仪、李光弼出井陉收复常山，正是这条路。**

## 十一、历史知识卡片

**1｜晋阳的来历** 春秋末年，赵鞅家臣董安于在汾水之滨筑晋阳城。此后赵氏以晋阳为根基，参与"三家分晋"。这座城后来做过太原郡治、北齐别都、隋太原郡治，一直是北方的军政重镇。

**2｜隋之晋阳宫** 隋代在晋阳建行宫。2015—2018 年，考古人员在晋阳古城二号建筑基址中出土了"隋之晋阳宫"残碑，为寻找隋代宫城范围提供了关键线索。这是文献与实物互证的典型案例。

**3｜617 年晋阳起兵** 大业十三年（617）五月，太原留守李渊杀监军王威、高君雅，开仓赈民，起兵南下。七月出发，十一月入长安，次年建唐。唐朝的起点，就在晋阳。

**4｜北都与北京** 天授元年（690）武则天置北都，并州改太原府；开元十一年（723）复置北都；天宝元年（742）改称北京。太原由此成为唐代的陪都，地位仅次于长安、洛阳。

**5｜河东节度使** 河东节度使治太原府，统天兵、大同、横野等军，兵力约五万余。它的任务是屏障关中、控扼河北，是唐玄宗十节度中地位特殊的一镇。

**6｜晋祠** 晋祠在晋阳城西南悬瓮山下，祀周成王弟唐叔虞，难老泉自祠下涌出，灌溉晋水灌区。祠内圣母殿、鱼沼飞梁为宋代建筑，唐太宗《晋祠铭》碑为唐初名碑。

**7｜鱼沼飞梁** 晋祠鱼沼飞梁是中国现存最早的十字形石桥之一，桥面十字交叉，架于方形水池之上。虽为宋代遗构，但其形制可上溯更早，是晋祠最独特的建筑。

**8｜井陉与太行八陉** 太行山有八条穿越通道，称"太行八陉"，井陉是第五陉。从太原东出井陉，可直抵恒州（今正定）、赵州，威胁范阳后路。757 年郭子仪、李光弼正是走这条路。

**9｜娘子关** 娘子关在今山西平定东北，古称苇泽关，是晋东门户。民间传说李渊之女平阳公主曾率"娘子军"驻此，关因此得名。此说**未见正史确证**，属地方传说。

**10｜757 年太原保卫战** 至德二载，史思明率十万众围太原，李光弼以万人守城，挖地道、筑土山、以抛石机击敌，坚守月余，终破围。这是安史之乱中防守战的典范。

**11｜晋阳之毁** 太平兴国四年（979），宋灭北汉，宋太宗以晋阳"王气"太盛，下令毁城，另建太原新城。千年古城自此湮没，直到现代考古重新发现它。
