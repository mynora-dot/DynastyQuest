# 敦煌与河西走廊

> 本档覆盖河西五州（凉、甘、肃、瓜、沙）与敦煌石窟、藏经洞。**特别提示**：藏经洞文书主体为唐后期至宋初，不可当作隋代材料使用。标记：**A** 正史或考古实测可互证；**B** 有据而细节有异说；**C** 异说并列；**D** 游戏推演。

**一句话定位**：河西走廊是一条被祁连山雪水串起来的绿洲链。中原王朝握住它，就握住西域；丢了它，关中就直接暴露。敦煌是这条链的末端，也是文明交汇的最前沿。

## 三、地理环境

| 要素 | 内容 | 意义 |
|---|---|---|
| 走廊 | 南为祁连山，北为合黎山、龙首山、马鬃山，中间狭长平地 | 东西千余里，南北数十里至百余里 |
| 水源 | 祁连山雪水汇成石羊河、黑河（弱水）、疏勒河、党河 | 每条河养活一片绿洲，绿洲连成通道 |
| 绿洲 | 武威、张掖、酒泉、敦煌—瓜州四大绿洲 | 商队补给、屯田、设郡 |
| 关隘 | 玉门关（敦煌西北，汉小方盘城）、阳关（敦煌西南，古董滩） | 西出西域的南北两道起点 |
| 沙漠 | 塔克拉玛干、库姆塔格、巴丹吉林 | 商道须依绿洲与井泉 |
| 周边 | 东接陇右（秦州、兰州），西出西域（伊州、西州、龟兹） | 中原—西域的咽喉 |

**玉门关与阳关**：汉代玉门关在今敦煌西北的小方盘城一带，阳关在今敦煌西南古董滩附近。唐代玉门关东迁至瓜州境内，具体位置学界有异说（C）。**"西出阳关无故人""春风不度玉门关"，咏的是唐人心中的这条界线。**

## 十一、历史知识卡片

**1｜河西四郡** 汉武帝击败匈奴后，先后置武威、张掖、酒泉、敦煌四郡，把河西走廊纳入版图。"武威"示军威，"张掖"取"张国臂掖"，"敦煌"意为"盛大"。四郡连成一线，就是中原通往西域的走廊。

**2｜裴矩经营西域** 隋大业年间，裴矩在张掖主持与西域商人的互市，收集各国山川、风俗、物产，撰成《西域图记》三卷。大业五年（609），炀帝西巡至张掖，高昌王麴伯雅等西域君主前来朝见。

**3｜安西都护府** 贞观十四年（640）唐灭高昌，置西州、庭州，并在交河城设安西都护府。显庆三年（658）移治龟兹，统辖安西四镇。这是唐朝经营西域的军政中枢。

**4｜河西节度使** 天宝年间置河西节度使，治凉州，统凉、甘、肃、瓜、沙等州，任务是隔断吐蕃与突厥。安史之乱爆发后，河西精兵内调平叛，吐蕃乘虚而入。

**5｜玉门关与阳关** 汉代玉门关在今敦煌西北的小方盘城，阳关在今敦煌西南古董滩，是西出西域的南北两道起点。唐代玉门关东迁至瓜州境内。"西出阳关无故人"，说的就是这里。

**6｜玄奘出关** 贞观初年，玄奘为求佛法，未经批准私自西行，从玉门关附近偷渡出关，穿越莫贺延碛，抵高昌，得麴文泰供养。他的《大唐西域记》是研究西域史地的一等史料。

**7｜莫高窟** 相传前秦建元二年（366）僧人乐僔在鸣沙山东麓开凿第一窟。此后历经北凉、北魏、西魏、北周、隋、唐、五代、宋、西夏、元，形成巨大的石窟群，现存洞窟数百个。

**8｜藏经洞是什么年代的** 莫高窟第 17 窟藏经洞出土文书约五六万件，写刻年代上起六朝，下迄宋初，最早有纪年的为 393 年，最晚为 1002 年。**主体是唐后期至宋初，不能当作隋代材料使用。**

**9｜沙州陷蕃与归义军** 安史之乱后吐蕃攻占河西，沙州约在 781 年（一说贞元初）陷落，与中原隔绝六十余年。大中二年（848）张议潮起兵收复沙州，建立归义军，遣使归唐。

**10｜藏经洞的发现** 1900 年，道士王圆箓在清理莫高窟第 17 窟积沙时发现藏经洞，内藏大量写本、印本、绢画。此后英、法、俄、日等国探险家接踵而至，文物大量外流，敦煌学由此成为国际显学。

**11｜敦煌文书的史料价值** 敦煌文书中保存了户籍、契约、诉状、账簿、书仪、图经等世俗文书，填补了正史对基层社会记载的空白，也纠正了传世史书的一些错误，如张议潮收复敦煌的年代。

## 十二、历史真实性与争议

| 问题 | 通行说法 | 争议 | 处理 |
|---|---|---|---|
| 沙州陷蕃年代 | 建中二年（781） | 敦煌文书中另有贞元初年之说 | 标 C |
| 张议潮收复沙州 | 大中二年（848） | 传世史籍记大中五年（851）为报捷至长安之年 | 标 C |
| 唐玉门关位置 | 东迁至瓜州境 | 具体地点有异说 | 标 C |
| 莫高窟窟数 | 735 个（通行统计） | 分区、计数口径不同 | 标 B |
| 隋代洞窟数 | 说法不一 | 分期研究仍在进行 | 标"待考证" |
| 藏经洞封闭原因 | 避难说、废弃说等 | 学界无定论 | 标 C |
| 乐僔开窟年代 | 366 年 | 属传说性质，见于后世碑记 | 标 B |

**特别警示**：①藏经洞文书不能用来说明隋代敦煌；②"敦煌文书"中大量是唐后期至宋初的世俗文书，写剧本时须核对年代；③玉门关汉唐异地，不可混写。
