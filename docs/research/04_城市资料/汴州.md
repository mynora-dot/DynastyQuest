# 汴州

> 通济渠上最重要的中转站，城址深埋于今开封地下。本档与《02_大运河专题/大运河沿线城市.md》互见。标记：**A** 正史或考古实测可互证；**B** 有据而细节有异说；**C** 异说并列；**D** 游戏推演。

## 一、基本信息

| 项目 | 内容 |
|---|---|
| 历史名称 | 隋：**汴州**（治浚仪）；唐：汴州（天宝元年—乾元元年改陈留郡，后复汴州） |
| 所属朝代 | 北周置州（576）；隋、唐因之；唐后期为宣武军节度使驻地 |
| 行政地位 | 州治（浚仪县）；唐宣武军节度使（781 年后）治所，管汴、宋、亳、颍等州 |
| 现代地理位置 | 河南省开封市。隋唐汴州城遗址深埋于今开封市区地下，北宋东京城、明清开封城层层叠压其上 |
| 规模 | 州城，面积远小于两京；具体城垣范围与周长**待考证**（城址深埋，发掘受限） |
| 重要程度 | ★★★★ 通济渠中段咽喉，江淮粮船必经；唐后期中原第一军镇 |
| 核心史料 | 《隋书》卷三、卷三〇《地理志中》；《旧唐书》卷三八《地理志一》；《资治通鉴》卷二一七、卷二三一 |

**一句话定位**：汴州的全部价值在于"过手"——江淮的粮、帛、盐经此北上，河北的兵、马经此南下。它自己不出产什么，却卡住了帝国的食道。

## 三、地理环境

| 要素 | 内容 | 意义 |
|---|---|---|
| 平原 | 黄淮平原，地势低平 | 无险可守，靠水与城 |
| 汴河 | 通济渠（唐称汴河）自西向东，经州城南/东 | 漕运主干，城市的生命线 |
| 黄河 | 城北数十里；汴口（板渚）为引河处 | 黄河决溢是汴州最大的自然威胁 |
| 湖泊沼泽 | 城周围多洼地、陂泽 | 排水与防洪难题 |
| 周边 | 郑州（西）、宋州（东）、陈留、中牟、尉氏 | 漕运与驿道节点 |

**地理要害**：汴州一马平川，无山可依，所以它的防御全靠城墙与河堤。黄河一旦决口，城即被泥沙掩埋——今天开封地下叠压六座城，正是这个地理条件的长期结果。

## 十一、历史知识卡片

**1｜汴州为什么重要** 通济渠从板渚引黄河水东南入淮，汴州正卡在中段。江淮的粮船要北上，必须从这里过。谁控制汴州，谁就掐住了关中的粮道。

**2｜汴州之名** 北周置汴州，治浚仪。"汴"取自汴水（通济渠的一段）。隋唐因之，天宝年间一度改称陈留郡。今天的开封，就是在这个城址上层层叠压长出来的。

**3｜城摞城** 开封地下 3 米至 12 米处，上下叠压着六座城池：清开封城、明开封城、金汴京城、北宋东京城、唐汴州城，最下层是战国大梁城（尚未发现）。各代中轴线几乎没有变动。

**4｜考古为什么难** 黄河多次决口，泥沙把古城深埋地下，加上地下水位高，隋唐汴州城无法大规模发掘。我们对它的认识，主要来自零星钻探、文献记载和对北宋东京城的参照。

**5｜宣武军** 建中二年（781）置宣武军节度使，治汴州，管汴、宋、亳、颍等州。此后一百多年，宣武军是中原最强悍的军镇之一，牙兵骄横，节度使更替频繁。

**6｜李希烈据汴称帝** 兴元元年（784），淮西节度使李希烈攻据汴州，在此称帝，国号楚。漕运再次中断，唐廷震动。这是汴州军事地位超过行政地位的一个标志性事件。

**7｜朱温的基业** 中和三年（883），朱温任宣武军节度使，以汴州为根据地，逐步吞并中原诸镇，终代唐建后梁，以汴州为东京。汴州的地位，自此从"漕运节点"升为"都城"。

**8｜汴河与黄河** 通济渠引黄河水为源，黄河含沙量大，汴河极易淤积。唐、宋两代不断清淤、改口，才维持通航。汴河的生命，是一场人与泥沙的长期拉锯。

**9｜州桥** 州桥跨汴河，是汴州城的交通中心。北宋时称"州桥"，明代仍存。唐代此处是否有桥、桥名为何，文献不足，**待考证**。游戏中可用"州桥"之名，但要标注为后世称呼。

**10｜河市与草市** 沿汴河形成的交易场所，交易不限于白天，唐后期已出现夜市雏形。汴州的市井气，比长安、洛阳浓得多——它是一座因商而生的城。

## 十二、历史真实性与争议

| 问题 | 通行说法 | 争议 | 处理 |
|---|---|---|---|
| 隋代汴州建置 | 开皇置汴州，大业废入郡 | 浚仪隋代隶何郡、何时废州，记载简略 | 标 C/待考证 |
| 城址位置与规模 | 深埋今开封地下 | 城垣范围、城门数目均无实测 | 标 C |
| 汴河穿城还是傍城 | 说法不一 | 隋唐汴河走向与今开封城关系有争议 | 标 C |
| 州桥年代 | 宋代确凿 | 唐代是否有桥待考 | 标"待考证" |
| 李勉镇汴事迹 | 有修城抚民之说 | 具体年代与工程内容待考 | 标 C |
| 李希烈称帝地点 | 汴州 | 细节（时间、国号）诸书略异 | 标 B |

**易错点**：①不可直接套用北宋东京城布局（三重城、御街、汴河穿城）；②隋代不得出现"宣武军"；③"州桥"是后世称呼；④汴州城规模远小于两京，不要画成都城。
