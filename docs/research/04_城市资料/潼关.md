# 潼关

> 潼关是关中东面的最后一道门。本档处理**关址三迁**（汉潼关—隋潼关—唐潼关）与 756 年的失守。标记：**A** 正史或考古实测可互证；**B** 有据而细节有异说；**C** 异说并列；**D** 游戏推演。

---

## 一、基本信息

| 项目 | 内容 |
|---|---|
| 历史名称 | 潼关；北朝一度改称"潼谷关"；隋唐又有"连城关"之说 |
| 所属朝代 | 东汉末置关（建安中）；隋、唐为京师东面门户 |
| 行政地位 | 关津，非州县治所；唐属华州华阴县境（B），设关令、关丞，驻军戍守 |
| 现代地理位置 | 陕西省渭南市潼关县港口镇一带。今潼关县城已迁，老城为明清潼关故城遗址，紧邻黄河与河南灵宝 |
| 关址变迁 | 汉潼关（今港口镇杨家庄、城北村一带）→ 隋大业七年（611）迁于南北连城关之间的坑兽槛谷（今港口镇禁沟口附近）→ 唐天授二年（691）再迁近黄河（今港口镇旧城址）（C） |
| 重要程度 | ★★★★ 关中门户；潼关失守则长安不保 |
| 核心史料 | 《后汉书》卷九《献帝纪》；《隋书》卷三；《旧唐书》卷一〇四《哥舒翰传》；《资治通鉴》卷二一八；《元和郡县图志》华州条 |

**一句话定位**：潼关不是一座城，是一道"门枢"——它把崤函古道、黄河与关中平原锁在一起，谁握住它，谁就握住长安的呼吸。

## 三、地理环境

| 要素 | 内容 | 意义 |
|---|---|---|
| 黄河 | 自北向南折而东流，潼关正当河曲 | 关北以河为险，渡口即风陵渡 |
| 塬地 | 关城依塬而筑，塬高河低 | 居高临下，控制河道与古道 |
| 禁沟 | 关南深沟，与潼水相配合 | 天然壕堑，骑兵难越 |
| 潼水 | 自南向北入黄河 | 关城水源，亦为城南屏障 |
| 山岭 | 南依秦岭华山，北临河，东西为崤函古道 | "一夫当关"的地形基础 |
| 古道 | 崤函古道：洛阳—陕州—硖石—灵宝—阌乡—潼关—华阴—长安 | 关中与中原唯一的低平通道 |

**地理要害**：关中以东，黄河与秦岭之间只有一条狭窄的黄土塬通道可行大军。潼关卡在这条通道的西口，所以自东汉设关以来，凡攻关中者必先取潼关。

## 四、城市布局

| 要素 | 汉潼关 | 隋潼关 | 唐潼关 |
|---|---|---|---|
| 位置 | 今港口镇杨家庄、城北村一带，东起原望沟西沿，西穿城北村至禁沟东岸 | 南北连城关之间的坑兽槛谷（今禁沟口附近） | 近黄河，今港口镇旧城址 |
| 形制 | 两面临沟，地势平坦开阔，遗迹可见 | 与"连城关"南北相连（此说出于后世考订，C） | 建关楼，城外开挖堑沟 |
| 防御要点 | 依禁沟、原望沟 | 依谷道与连城 | 依河、依塬、依堑 |

**关城构成的通行认识（B）**：关楼、关门、夯土关墙、戍卒营房、驿馆、关市。唐关城的周长、门数无确切记载，**待考证**；今日所见的潼关故城格局主要是明洪武九年扩建后的形态（周回 11.2 公里，六门：东"金陡"、西"怀远"、上南门、下南门、大北门、小北门），不可直接当作唐关。

**十二连城与禁沟**：潼关东侧沿禁沟一线有烽堠、堡寨遗迹，后世称"十二连城"，与关城共同构成纵深防御（C，具体年代与数目待考）。

## 十一、历史知识卡片

**1｜潼关为什么叫潼关** 关西有潼水，北注黄河，"潼"即水名。东汉建安年间，献帝把函谷关西迁至此，潼关之名才开始行用。此后它逐渐取代函谷关，成为关中东面的大门。

**2｜汉潼关与隋唐潼关不是一处** 汉潼关在今港口镇杨家庄、城北村一带，两面临沟；隋大业七年（611）迁到南北连城关之间的坑兽槛谷；唐天授二年（691）再迁近黄河。**三处关址相距不远，但不是同一座城。**

**3｜崤函古道** 从洛阳西行，经陕州、硖石、灵宝、阌乡到潼关，再入华阴、长安。这条道大部分在黄土塬的沟壑间穿行，路窄而长，是关中与中原之间唯一能走大军的通道。

**4｜关中的四塞** 东有崤函潼关，东南有武关，西有散关，北有萧关。四塞之中，潼关离长安最近、承压最重。潼关一破，长安以东无险可守。

**5｜756 年潼关为什么失守** 哥舒翰主张据险坚守，杨国忠怕他拥兵自重，怂恿玄宗催战。唐军被迫出关，在灵宝西原被崔乾祐伏击。地形狭窄，唐军展不开阵形，大败。这不是兵力不足，是决策失误。

**6｜哥舒翰的结局** 哥舒翰是突骑施人，曾任河西、陇右节度使，战功卓著。756 年守潼关兵败被俘，押送洛阳，安庆绪败退时将其杀死。一位名将的最后一场仗，输在朝堂而非战场。

**7｜封常清与高仙芝之死** 755 年洛阳失守后，封常清、高仙芝退守潼关，坚壁不出。监军宦官边令诚诬其克扣军粮，二人被玄宗下诏处死。军前斩将，士气大伤，潼关之败的伏笔早已埋下。

**8｜唐潼关城的形制** 唐关城依塬临河，建关楼，城外开堑沟。今日所见的潼关故城是明洪武九年扩建后的样子：周回 11.2 公里，六座城门，把麒麟山、凤凰山等囊括城中。**不要把明城当作唐城。**

**9｜禁沟与十二连城** 潼关南面的禁沟是一道深沟，与潼水一起构成天然壕堑。沿沟一线有堡寨、烽堠遗迹，后世称"十二连城"，与关城形成纵深。绕关偷渡，多走这条沟。

**10｜880 年黄巢破关** 广明元年，黄巢军攻关，唐将齐克让力战不支，潼关失守。僖宗仓皇奔蜀，与一百多年后的玄宗走的是同一条路。潼关的得失，几乎就是唐廷安危的晴雨表。

## 十二、历史真实性与争议

| 问题 | 通行说法 | 争议 | 处理 |
|---|---|---|---|
| 关址三迁的具体位置 | 汉关在杨家庄、城北村；隋关在禁沟口；唐关在港口旧城 | 各址范围与年代仍有讨论 | 标 C |
| 隋是否另建"连城关" | 后世考订认为隋利用北朝小关并在其北增建连城关 | 属研究推论，非定论 | 标 C |
| 唐关城规模 | 无确切记载 | 周长、门数待考 | 标"待考证" |
| 灵宝之战兵力 | 唐军约二十万（号） | 数字或有夸大 | 标 B |
| 潼关唐属何县 | 华州华阴县 | 关津地位特殊，隶属有异说 | 标 B |
| 十二连城年代 | 与关城同时或更晚 | 具体营建年代待考 | 标 C |

**易错点**：①汉、隋、唐潼关是三个关址，不可混写；②明洪武扩建后的城制不能套用到唐；③"潼关"之名始于东汉末，秦时为函谷关；④哥舒翰被俘后被杀于 757 年，非 756 年阵亡。
