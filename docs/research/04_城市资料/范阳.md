# 范阳（隋涿郡·唐幽州）

> 同一地区的三个名字：隋**涿郡**、唐**幽州**、天宝**范阳郡**。本档重点是永济渠北端与 755 年安禄山起兵。标记：**A** 正史或考古实测可互证；**B** 有据而细节有异说；**C** 异说并列；**D** 游戏推演。

---

## 一、基本信息

| 项目 | 内容 |
|---|---|
| 历史名称 | 隋：**涿郡**（治蓟县）；唐：**幽州**（天宝元年—乾元元年改范阳郡，后复幽州）；节度使名"范阳" |
| 所属朝代 | 隋 607—618（涿郡）；唐 618—907（幽州） |
| 行政地位 | 隋郡治，征辽后勤总基地；唐幽州大都督府、范阳节度使（天宝后）驻地，唐后期卢龙节度使治所 |
| 现代地理位置 | 北京市城区西南，蓟城遗址约在今广安门内外一带；辽南京、金中都均因其旧址 |
| 规模 | 城址范围与周长**待考证**；唐幽州为北方军事重镇，城内西南隅有子城 |
| 重要程度 | ★★★★ 永济渠北端终点、东北军事中枢、安史之乱的策源地 |
| 核心史料 | 《隋书》卷三、卷六八《阎毗传》；《旧唐书》卷三九《地理志二》、卷二〇〇上《安禄山传》；《资治通鉴》卷一八一、卷二一七 |

**一句话定位**：涿郡是隋炀帝为打高句丽而喂养出来的军事城市，幽州是唐帝国为防契丹而设的军区，范阳则是安禄山用来掀翻帝国的本钱——**同一个城，三种用途**。

## 三、地理环境

| 要素 | 内容 | 意义 |
|---|---|---|
| 平原 | 华北平原北端，督亢沃野 | 粮食可自给一部分，但大军集结仍需漕运 |
| 山脉 | 北倚燕山，西接太行 | 居庸关、古北口、榆关为北出孔道 |
| 河流 | 桑干河（今永定河）、清泉河（蓟城南七里，见《魏土地记》） | 城址择于两水之间的高地 |
| 台地 | 蓟丘，在城中西北隅 | 城名所本，亦为制高点 |
| 运河 | 永济渠北端至此 | 江淮粮械可水运直达，是征辽的生命线 |
| 周边 | 檀州（密云）、妫州（怀来）、平州（卢龙）、瀛州、莫州 | 东北防线上的连锁军镇 |

**军事地理要点**：幽州是中原王朝控扼东北的支点。北出居庸可制奚、契丹，东出榆关可通辽东，南沿永济渠可吸江淮之粮。**谁坐幽州，谁就握有"以边兵制中央"的资本**——安禄山正是靠这一点起兵。

## 十一、历史知识卡片

**1｜涿郡、幽州、范阳是同一个地方** 隋大业三年改州为郡，幽州改称涿郡，治蓟县；唐初复为幽州；天宝元年改范阳郡，节度使也随之称范阳节度使。三个名字对应三个时代，写故事要跟着年代换。

**2｜永济渠的北端** 大业四年（608）开永济渠，"引沁水南达于河，北通涿郡"。江淮粮船可经此直达涿郡，为征高句丽做准备。北段是否通到城下、是否借桑干水道，学界有争议。

**3｜阎毗与临朔宫** 《隋书·阎毗传》记："将兴辽东之役，自洛口开渠，达于涿郡，以通运漕。毗督其役。明年，兼领右翊卫长史，营建临朔宫。"一位工艺家，把运河与行宫一起修到了涿郡。

**4｜611 年的征兵** 大业七年，炀帝下诏征天下兵会涿郡，准备征高句丽。动员规模空前，粮运压垮了山东、河北的民力，王薄起义就发生在这一年。

**5｜蓟城在哪里** 唐幽州蓟城约在今北京广安门内外一带。辽南京、金中都沿其旧址，明清北京城则在其东北方向扩展。所以不能用明清北京城的格局去套唐幽州。

**6｜子城在西南角** 唐幽州城内西南隅有子城，是都督府、节度使衙署所在。据唐墓志与文献推定，子城东、北墙在城内，西、南墙傍附大城城垣。安禄山的起兵，就从这里发出。

**7｜悯忠寺** 贞观十九年（645）唐太宗征高句丽无功而返，回师幽州，为阵亡将士建寺，即悯忠寺，是今法源寺的前身。寺在"燕城东南隅"，是幽州最重要的佛寺。

**8｜范阳节度使的兵力** 天宝元年，范阳节度使统经略、威武、清夷、静塞、恒阳、北平、高阳、唐兴、横海等军，兵力约九万余人（《资治通鉴》，数字有异说）。安禄山兼三镇后，拥兵近二十万。

**9｜755 年十一月的那一天** 安禄山以"奉密诏讨杨国忠"为名，在范阳起兵，率十五万（号二十万）南下。唐廷承平已久，河北州县望风瓦解。七年多的安史之乱自此开始。

**10｜幽州之后** 安史之乱平定后，李怀仙以幽州降唐，任卢龙节度使。此后幽州长期半独立，成为唐后期藩镇割据的典型。**"范阳"这个名字，从此与"骄兵悍将"绑在一起。**

## 十二、历史真实性与争议

| 问题 | 通行说法 | 争议 | 处理 |
|---|---|---|---|
| 永济渠北端 | "北通涿郡" | 是否直达城下、是否借桑干水道 | 标 C |
| 蓟城范围 | 今广安门一带 | 具体城垣走向与周长待考 | 标 B/待考证 |
| 临朔宫位置 | 蓟城附近 | 一说在城南，具体待考 | 标 C |
| 范阳节度使设置年 | 742 年改称 | 前身幽州节度使置于睿宗、玄宗之际 | 标 B |
| 安禄山任范阳节度使年 | 745 年（基准表） | 诸书记载略有出入 | 依基准表，标 B |
| 范阳兵力 | 九万余（《通鉴》） | 数字或有夸大 | 标 B |
| 蓟城城门数 | "开十门" | 减去子城二门为八门，属推论 | 标 C |

**易错点**：①隋代写"涿郡"，天宝写"范阳"，唐初写"幽州"，不可混用；②临朔宫为隋建筑，唐章不应出现；③"节度使"不得用于隋代；④悯忠寺建于 645 年，隋章不可出现。

**古籍**：《水经注》㶟水条；《太平寰宇记》引《郡国志》；《日下旧闻考》卷六十。

**考古资料**：北京城区唐墓志（记墓地与幽州城垣相对位置）与陶井群调查资料，相关报告篇目待核。

**现代论著（未逐页核对）**：鲁西奇《中国历史的空间结构》，广西师范大学出版社；北京市文物研究所相关北京城市考古论著。
