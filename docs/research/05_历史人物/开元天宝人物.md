# 开元天宝人物（713—755）

> **断限与依据**：本文件收录开元（713—741）至天宝十四载（755）人物 28 人。安禄山起兵之后的经历归 `安史之乱人物.md`，本文件只写到 755 年十一月为止。
>
> **可信度标记**：A 正史本纪/传明确且可互证；B 细节有异说或年份系逆推；C 学界异说；D 游戏推演。
>
> **生卒年原则**：盛唐人物生年多无直接记载，除有墓志、正史明载者外，一律标 B 或"（生年待考证）"。
>
> **时代称谓**：742 年起"年"改称"载"；742—758 年州改郡，称"太守"不称"刺史"；"节度使"711 年后始有，开元天宝间已为常制，可用。

## 人物关系网络

开元天宝的关系结构是**"皇帝—宰相—边将"三角**：玄宗以宰相制衡边将，又以边将制衡宰相，最终两者合流为安禄山。

**三条主线**：
1. **宰相更替线**：姚崇→宋璟→张说→张九龄→李林甫→杨国忠，贤相递减、权相递增，与漕运管理的松紧同步。
2. **边将体系线**：王忠嗣（四镇）→哥舒翰（陇右）、安禄山（三镇）、高仙芝（安西）、封常清（北庭），蕃将坐大而中央无兵。
3. **文艺网络线**：贺知章—李白—杜甫—王维—吴道子，以两京—运河为活动轴，构成盛唐文化圈。
