## 一、制度起源：仓廪是帝国的神经末梢

隋唐仓廪体系不是简单的"存粮"，而是三套需求的叠加：

1. **京师供养**：长安、洛阳人口庞大，关中不足以自给，必须漕运关东、江淮之粟。
2. **灾荒赈济**：义仓、常平仓就地备荒。
3. **军事后勤**：边镇军仓、屯田、和籴配套。

隋文帝一朝"中外仓库，无不盈积"，至隋末，仓廪之富反成群雄争夺的目标——李密取洛口仓，李渊取永丰仓，皆因"得仓者得粮，得粮者得众"（B）。这提示一条重要的设计原则：**仓在游戏中不只是背景，而是权力节点**。

### 2.2 唐代增置

开元二十二年（734）裴耀卿置**河阴仓、柏崖仓、集津仓、盐仓**等中转仓；天宝年间又增置多所。**含嘉仓**始建年代旧说隋建，今考为唐贞观至永徽间（627—655），属唐仓（C，详见 `../02_大运河专题/大运河工程技术.md`）。

**"监"与"监临"**：仓官属"监临官"，若监守自盗，罪加一等；若失于觉察，亦连带受罚（《唐律疏议》卷一九《贼盗》；B）。这条法律给了游戏一个天然的案件类型：**仓粮亏空，谁负责？**

## 四、运作机制（三）：账簿与勾检

唐代仓廪管理是一套**文簿驱动的系统**，实物与文书必须互证。

| 文书 | 载体 | 内容 | 考古实证 |
|---|---|---|---|
| **铭砖** | 砖 | 仓号、粮种、来源、数量、入仓年份、经手人 | 含嘉仓出土，A |
| 帐 | 纸 | 年度出入总账 | 敦煌文书有残卷，B |
| 簿 | 纸 | 分仓、分品种明细 | B |
| 牒 | 纸 | 申禀、勘验、调拨 | B |
| 勾帐 | 纸 | 比部勾覆后的核销账 | B |

**铭砖的意义**：它把"这一窖粮"变成了可追溯的物件——来自何州、何年入仓、何人经手。这是唐代仓储管理最硬的证据，也是最好的解谜道具。

**勾检制度**：刑部**比部**掌勾覆中外帐籍，定期核查各部门收支。仓粮账目须经比部勾检，方能核销（《唐六典》卷六；B）。

> 唐代帐簿已见"承前""新收""支破""见在"的分项记录，但**完整的"四柱结算法"定型于宋**，游戏中不宜让唐人自称"四柱"（B）。

## 五、运作机制（四）：损耗与加耗

| 损耗类型 | 成因 | 处理 |
|---|---|---|
| 鼠雀耗 | 鼠啮雀食 | 定额报销，超额追赔 |
| 抛撒 | 装卸、量米时的撒漏 | 计入损耗 |
| 霉变 | 潮湿、通风不良 | 翻晒、倒窖 |
| 水湿 | 雨漏、地下水 | 防潮层、排水沟 |
| 盗卖 | 仓吏、斗级舞弊 | 法律严惩，但仍普遍 |

**加耗**：征收与转运时，为弥补上述损耗而附加征收一定比例，称"加耗"。比例各州不同，无统一令文（B）。加耗是基层吏员最重要的灰色收入来源，也是民怨焦点。

**防潮工艺**（考古实证，A）：窖壁与窖底先经火烤，再铺木板、席子、谷糠、草束，分层夯实；窖口封土，形成密闭环境。含嘉仓一座窖内保存的粟米在千年后仍有部分可辨。

## 六、运作机制（五）：转般法

唐初漕粮直运长安，三门峡段损耗极大。开元二十二年（734），裴耀卿改革，核心是"**分段转运、节级递送**"：

```
江淮船 → 河阴仓（卸）→ 黄河船 → 洛口/洛阳 → 陆运过三门 → 太原仓 → 渭水船 → 太仓
```

制度要点：

| 要点 | 内容 | 级别 |
|---|---|---|
| 中转仓设置 | 河阴、柏崖、集津、盐仓 | B |
| 分段承包 | 各段由熟悉水性的本地船户承运 | B |
| 纲运 | 以"纲"为单位编组船只，设押纲官 | B |
| 定额 | 每纲载粮有定额，超欠有赏罚 | B |
| 成效 | "凡三岁，漕七百万石" | B |

（《旧唐书》卷四九《食货志下》；B，数字有异说）

**"纲"是理解唐代漕运的关键词**：它不是"船队"的泛称，而是有编制、有押官、有定额、有赏罚的**运输单元**。游戏里可以让玩家"押一纲"，承担定额与损耗责任。

## 七、运作机制（六）：仓储与粮价调控

| 手段 | 操作 | 目的 |
|---|---|---|
| 常平籴粜 | 谷贱时加价而籴，谷贵时减价而粜 | 平抑粮价 |
| 和籴 | 官府按价向民间购粮 | 充实军仓、京师仓 |
| 义仓赈济 | 灾年就地开仓 | 救荒 |
| 仓粮出贷 | 春借秋还，收薄息 | 救济与增殖（B） |

**和籴的异化**：名为"和"（自愿），实则常带强制摊派。天宝年间李林甫"增近道粟赋及和籴以实关中"，数年"蓄积稍丰"（《资治通鉴》卷二一五；A）——这背后是关中农户的额外负担。

| 阶段 | 仓廪与漕运体制 | 关键 |
|---|---|---|
| 隋 581—618 | 仓城大兴：黎阳、洛口、回洛、子罗；漕渠初通 | 因需而运，无常制；仓廪极富 |
| 唐初—贞观 618—649 | 沿用隋仓；含嘉仓始建（627—655） | 漕粮直运长安，三门损耗巨大 |
| 高宗武周 649—705 | 东都地位上升，转运量增加 | 洛阳仓场成为枢纽 |

## 十、与百姓的关系

1. **正仓的粮来自百姓的租**，义仓的粮也来自百姓的亩税——仓廪之富，是民力之竭的另一面。
2. **常平仓在灾年开仓**，是百姓最直接的救命渠道，也是地方官最重要的政绩。
3. **斗级的一脚**：量米时"踢斛淋尖"，多收的粮食归仓或入私囊，百姓最恨。
4. **加耗**：纸面二石，实缴可能二石二斗。
5. **仓吏的账**：账实不符时，最先被追赔的往往是最底层的仓夫。

## 十一、历史影响

1. **隋唐仓廪体系是中国古代仓储制度的高峰**，其"正仓—转运仓—太仓"三级结构与"常平—义仓"双轨备荒，为宋以后所继承。
2. **转般法**奠定了此后千年漕运"分段接运"的基本思路，刘晏改革即在其基础上展开。
3. **铭砖与勾检制度**体现了相当成熟的"实物—文书"双轨管理技术，是中国古代行政技术的代表作。
4. **仓储的过度集中**也带来风险：一旦仓城失守，政权即刻失去物质基础。隋末群雄争仓，即为明证。

## 十二、可转化游戏任务

### 任务一：铭砖对账

- **背景**：含嘉仓某窖铭砖记"粟一万二千石"，账册记"一万一千五百石"，实存不足一万。
- **目标**：查明差额去向（损耗？盗卖？记错？），并填写勘验牒。
- **玩法**：账实核对解谜。玩家比对铭砖、帐簿、出入牒三方，逐项排除；正确答案可能不止一个。
- **知识点**：铭砖内容；帐簿勾检；损耗定额；监临官责任。
- **真实性说明**：铭砖制度与含嘉仓数据为 A；案件为 D。

### 任务二：押一纲

- **背景**：玩家受命押运一纲漕粮，从河阴仓至太原仓，途中过三门。
- **目标**：在定额之内把粮运到，损耗不得超过规定。
- **玩法**：资源与风险管理。玩家要分配船工、选择过滩时机、处理鼠患与水湿，每个决策都影响最终损耗率。
- **知识点**：纲运编制；押纲官责任；分段转运；损耗与加耗。
- **真实性说明**：纲运与转般法为 B；具体数值为 D。

### 任务三：常平开仓

- **背景**：某州大旱，常平仓存粟五万石，州司请示"是否减价出粜"。
- **目标**：在"平抑粮价"与"保住军需"之间做出决策，并承担后果。
- **玩法**：政策模拟。玩家设定出粜价格与数量，观察米价、民怨、军仓存粮三条曲线；决策失误会引发抢粮事件。
- **知识点**：常平籴粜；和籴的强制化；军需与民食的冲突。
- **真实性说明**：常平制度为 B；模拟为 D。

### 任务四：一脚踢出的官司

- **背景**：农户告斗级"踢斛淋尖"，多收三斗；斗级称"此是加耗"。
- **目标**：查明加耗的法定比例，判断斗级是否越界。
- **玩法**：庭审辩论。玩家扮演县尉，听取双方、查验量器、比对令文，作出判词。
- **知识点**：加耗；量器（斛、斗）；斗级的职责与舞弊手法。
- **真实性说明**：加耗为 B（比例无统一令文）；案件为 D。

### 任务五：仓城之夜（隋末）

- **背景**：大业末年，乱兵逼近洛口仓，仓吏欲开仓散粮、焚仓自保，或坚守待援。
- **目标**：在三日内做出抉择，并承担道义与后果。
- **玩法**：多结局叙事。三条路（散粮、焚仓、坚守）各有代价，玩家需先调查粮仓结构、守军人数、乱兵动向。
- **知识点**：隋代仓城规模；仓粮的政治意义；乱世中的基层抉择。
- **真实性说明**：隋末争仓为 B；情节为 D。

## 争议与待考证

1. **洛口仓、回洛仓的仓窖数**（B/C）：史载"三千窖""三百窖"带夸饰，考古勘探数字与之不合，本文并列不裁断。
2. **含嘉仓始建年代**（C）：旧说隋建，杨清越考为唐贞观至永徽间；本文采唐仓说并注明争议。
3. **回洛仓仓窖总数**（C）：考古勘探有二百余座、七百余座等不同表述。
4. **"三岁漕七百万石"的统计口径**（B）：是三年累计抑或年均，学界有不同理解。
5. **加耗的法定比例**（C）：未见统一令文，各州自定。
6. **唐代帐簿是否已具四柱形态**（C）：有"承前—新收—支破—见在"分项，但完整四柱定型于宋。
7. **隋代仓廪容量的总量估算**（C）：各家推算差异极大，本文不列。
