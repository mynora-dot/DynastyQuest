# 科举制度

> 本文件讲"一个读书人怎样从县里的考场走进尚书省，又怎样从及第走到授官"。科举是《隋唐行纪》里最能让玩家"以文入仕"的系统，也是最容易写错年代的制度。
>
> 标记：A 可靠 / B 有争议 / C 学界异说 / D 游戏推演。**进士科起于何年，是隋唐史最著名的公案之一，必须并陈异说。**

## 一、制度起源：两句话，三个年份

### 1.1 通行的两句话

- **隋文帝分科取士**：开皇年间废九品中正，诏"诸州岁贡三人"，以志行修谨、清平干济二科举人（《隋书》卷一《高祖纪上》；B）。
- **隋炀帝始建进士科**：唐人薛登、杨绾、杜佑、刘肃等众口一词，皆云"炀帝始建进士科"（C，但方向一致）。

### 1.2 "进士科始于何年"的异说（必须并列）

| 说法 | 具体年份 | 依据 | 代表意见 | 级别 |
|---|---|---|---|---|
| **大业元年说** | 605，一说在闰七月复国子学同时 | 《隋北地太守陈思道墓志》"公弱冠及进士第……以大业二年卒"；《隋书·炀帝纪》大业元年闰七月兴学诏 | 陈直（1963）首倡；刘海峰详证 | C |
| **大业二年说** | 606 | 《资治通鉴纲目》"炀帝大业二年始建进士科"；清代《古今图书集成·选举典》以此为《科举部》首条 | 旧史通说 | C |
| 开皇七年说 | 587 | 宫崎市定推论，无直接史料 | 日本学界旧说 | C |
| 开皇十五/十六年说 | 595/596 | 由房玄龄"年十八举进士"反推 | 邓嗣禹提出矛盾，后人推衍 | C |

**旁证**：《北史》卷二六《杜铨传》附《杜正藏传》载正藏"大业中"与刘炫同以学业该通应诏，"被举时，正藏弟正仪贡充进士，正伦为秀才"。此条同时出现"进士"与"秀才"两科，说明大业年间进士科确已独立存在（A/B）。

> **游戏处理**：不要让 NPC 斩钉截铁说"进士科始创于大业元年"。最稳妥的写法是让一位老儒说"炀帝时始有进士之举"，玩家若追问年份，得到两种说法互相矛盾的回答——这本身就是一场"史料辨伪"任务。

## 二、唐代常科

常科（常贡之科）每年举行。考生来源二分：由国子监、州县学出身的称**生徒**，由州县考送、不在学馆的称**乡贡**（《新唐书》卷四四《选举志上》；A）。

| 科目 | 考什么 | 地位与变迁 |
|---|---|---|
| 秀才 | 方略策五道 | 最高，然"举而不第者坐其州长"，故人不敢应，高宗永徽二年（651）停（B） |
| 明经 | 帖经、墨义、时务策 | 录取多，出路稳，地位次于进士 |
| 进士 | 帖经、杂文（诗赋）、策 | 最贵，"其得人亦最为盛" |
| 明法 | 律令 | 入法司 |
| 明字 | 《说文》《字林》 | 入书学相关官 |
| 明算 | 《九章》《海岛》等 | 入算学相关官 |

《新唐书》卷四四又有俊士、一史、三史、开元礼、道举、童子等目，多不常行（B）。

> **时代坑**：进士科加试杂文（诗赋）始于**调露二年（680）**刘思立之请，此前进士只试策。故写贞观年间的进士考试，不宜让考生"以诗赋定胜负"（B）。

## 三、制科：天子自诏

制科不定期，由皇帝下诏，科目名目繁多（贤良方正、直言极谏、博学宏词、超绝流俗等），及第者多可超擢。制科不属常贡，考试内容与等第随诏而定（《新唐书》卷四四；A/B）。

对游戏的价值：制科是"一夜之间改变命运"的合法通道，适合做**限时事件**——诏书到县，三十日内赴京。

## 四、运作机制：考试流程

```
州县考（乡贡）或学馆试（生徒）
   ↓  每年十月至十一月，州送举人赴京
省试（尚书省）—— 唐初由吏部考功员外郎主之
   ↓  开元二十四年（736）移礼部，侍郎主之
及第（"登第""擢第"）
   ↓  守选数年
吏部关试 → 铨选（身、言、书、判）
   ↓
释褐授官（多从九品）
```

**关键改制**：开元二十四年（736），考功员外郎李昂为举人诋诃，玄宗以其望轻，遂移贡举于礼部，以侍郎主之，"礼部选士自此始"（《新唐书》卷四四《选举志上》；A）。这条界线必须守住——736 年之前说"礼部试"，即为硬伤。

**吏部选**考"身、言、书、判"：体貌丰伟、言辞辩正、楷法遒美、文理优长；四事皆可取，则先德行（《新唐书》卷四五《选举志下》；B）。

## 五、糊名、行卷与公荐

### 5.1 糊名：唐后期，且证据薄弱（C）

唐代科举**基本不糊名**，考官知举子姓名，甚至"通榜"预定名次。糊名（封弥）成为定制在**北宋**。

唐后期出现的防弊措施主要是：

| 措施 | 内容 | 时代 |
|---|---|---|
| 别头试 | 考官亲属子弟另设考场 | 唐后期 |
| 覆试 | 及第者再考一次 | 唐后期 |
| 锁院 | 考官入贡院后锁门，不得外出 | 唐后期至宋 |

> **结论**：若游戏需要"糊名"机制，应标 C 并注明"唐代是否局部施行糊名，史料不足，通说认为定制于宋"。**不要**写成"唐代科举一律糊名"。

### 5.2 行卷与公荐（A）

举子于考试前将自己的诗文写成卷轴，投献权贵、前辈，称**行卷**；再由其人向主司推荐，称**公荐**。此风在盛唐极盛。

- 王维（699—761）以琵琶曲与诗卷干谒玉真公主，开元九年（721）擢第（《唐摭言》等；B，细节有传奇成分）。
- 白居易（772—846）初至长安，以《赋得古原草送别》谒顾况——此事在贞元年间，**已超出本作主线（763 年止）**，只能作知识卡。

行卷之弊在于"以文名定去留"，寒门无门路者处于劣势。北宋初遂严禁公荐。

## 六、录取人数

| 科目 | 每榜人数 | 说明 | 级别 |
|---|---|---|---|
| 进士 | 少则十余人，多则三四十人 | 唐 290 年间进士总数约六千余，年均二十余人 | B |
| 明经 | 约为进士的数倍 | "明经倍之，得第者十一二" | B |
| 制科 | 不定 | 一次可取数十人 | B |

《新唐书》卷四四有一句极传神的比例："进士大抵千人得第者百一二，明经倍之，得第者十一二。"（B，数字为概略）

故有"**三十老明经，五十少进士**"之谚（《唐摭言》卷一；A/B）——明经易得而人轻之，进士难取而人重之。

## 七、及第之后

及第**不等于做官**。进士登第后须"守选"，等待吏部铨选，短则一二年，长则十余年。期间可参加**关试**（试判两节），通过后方能"释褐"授官，起家多为九品。

放榜后有曲江宴、雁塔题名等礼俗（唐后期尤盛，B）。座主与门生由此结成政治关系网，是中晚唐朋党的温床。

---

## 八、武举（702）

**长安二年（702）**，武则天始置武举。其制有长垛、马射、步射、平射、筒射，又有马枪、翘关、负重、身材之选（《新唐书》卷四四《选举志上》；A）。

武举的意义：给"不能文"的将门与豪强子弟一条正途，也为开元、天宝的边军输送了一批中下层军官。但唐代武举规模远小于文举，且不常行（B）。

## 九、科举与门阀

| 阶段 | 关系 |
|---|---|
| 唐初 | 科举规模小，门荫仍是入仕主途；崔、卢、李、郑、王等旧族仍以门第自重 |
| 高宗武周 | 武则天广开科场、增设制科，扶植寒庶，打击关陇集团 |
| 开元 | 科举成为清望官主途，"进士"渐成社会身份符号 |
| 唐后期 | 牛李党争：李德裕重门第经术，牛僧孺党多由进士起家，科举成为党争焦点 |

科举并未消灭门阀，而是**把门阀的竞争场从"血统"移到"文化资本"**——世家大族凭借家学与藏书，在科场上仍占优势，直至唐末战乱才真正崩解。

## 十、时代变化

| 阶段 | 科举状况 | 关键 |
|---|---|---|
| 隋 581—618 | 分科取士初兴；进士科始建（605/606，C） | 废九品中正；秀才、明经、进士并立 |
| 唐初—贞观 618—649 | 科目粗备，录取极少，门荫仍是主途 | 秀才科渐废；进士只试策 |
| 高宗武周 649—705 | 广开科场、增设制科 | 武则天以科举抑关陇；载初元年（690）亲策贡士（B） |
| 开元 713—741 | 进士加试杂文；736 年贡举归礼部 | 诗赋取士成型；行卷公荐极盛 |
| 天宝 742—755 | 录取仍少，请托盛行 | 天宝六载（747）"野无遗贤"之事（A/B） |
| 安史乱后 755—763 | 科场时断时续，放榜从权 | 士人多避乱南迁 |

## 十一、与百姓的关系

1. **对多数农家，科举遥不可及**：读书需脱产、需书籍、需师承，成本极高。
2. **但它提供了一条"理论上公平"的路**：不问出身，只问文章——这在门阀社会中是革命性的观念。
3. **州县试是第一道门槛**：乡贡名额有限，寒门子弟常被地方豪族挤占。
4. **及第不等于脱贫**：守选数年仍需家中供养，故有举子长期困顿者。
5. **"三十老明经，五十少进士"**：一句谚语道尽两种人生。

## 十二、历史影响

1. **科举制是中国帝制时代最重要的人才选拔制度**，"考试取士"原则延续一千三百年。
2. **唐代进士科以诗赋取士**，直接推动了唐诗的繁荣与文人社会的形成。
3. **座主—门生关系**成为中晚唐朋党政治的组织基础。
4. **科举与门阀的博弈**最终以科举胜出告终，但世家大族凭借文化资本仍长期占优。
5. **别头试、覆试、锁院**等防弊技术，为宋代科举的严密化奠定基础。

## 十三、可转化游戏任务

### 任务一：大业元年的两种说法

- **背景**：玩家在洛阳书肆遇到两位老儒争论"进士科始于何年"，一人说大业元年，一人说大业二年，各执一书。
- **目标**：查阅三种文献，判断哪一说证据更强，或判定"无法定论"。
- **玩法**：文献比对。玩家可查阅《隋书》纪、《北史》传、墓志拓片，逐条评估证据强度；选"无法定论"亦可通关，但需说明理由。
- **知识点**：进士科起源的两种异说；墓志作为史料的证明力；"消极史料"的用法。
- **真实性说明**：异说与依据见刘海峰文（实访可读），属 C；两位老儒为虚构人物（D）。

### 任务二：行卷

- **背景**：开元年间，寒门举子携诗卷入长安，欲谒某位尚书，屡被门房挡回。
- **目标**：在三十日内让诗卷送到一位肯"公荐"的权贵手中。
- **玩法**：社交资源管理。玩家需在诗会、寺院、酒肆间经营名声，选择投献对象，权衡"投错人"的风险；诗作质量由小游戏（择韵、炼字）决定。
- **知识点**：行卷与公荐；盛唐举子的社交网络；"以文名定去留"的弊病。
- **真实性说明**：行卷、公荐为 A；具体人物与诗作为 D，不冒用真实作品。

### 任务三：一场省试

- **背景**：736 年，贡举刚从吏部移到礼部，第一场礼部试秩序混乱。
- **目标**：以举子身份完成帖经、杂文、策三场，并应对考场舞弊。
- **玩法**：三关答题 + 抉择。帖经考记忆（填空），杂文考诗赋（择句），策考时务（多选论证）；中途可发现邻座夹带，选择告发或沉默。
- **知识点**：进士科三场制；736 年贡举归礼部；考场防弊的早期形态。
- **真实性说明**：三场制与 736 年改制为 A；题目为拟作（D）。

### 任务四：守选

- **背景**：玩家已进士及第，却在家守选三年，家贫亲老，有人劝他走门路。
- **目标**：在"守选待官""干谒求荐""改应制科"三条路中做出选择，并承担后果。
- **玩法**：时间与资源管理。每条路消耗不同年数与钱财，触发不同结局（授官、蹉跎、被讥）。
- **知识点**：及第不等于授官；守选与铨选；制科作为捷径。
- **真实性说明**：守选、铨选为 A/B；结局为 D。

### 任务五：武举校场（702 年后）

- **背景**：长安二年首开武举，校场设长垛、马射、马枪、翘关。
- **目标**：通过三项以上，取得武举出身。
- **玩法**：动作/判定小游戏（射箭准度、马枪命中、负重）。可招募不同出身的陪练提升属性。
- **知识点**：武举科目；702 年始置；武人入仕的另一条路。
- **真实性说明**：科目见《新唐书》卷四四，A；具体规则细节为 D。

## 争议与待考证

1. **进士科起始年**（C）：大业元年（605）与大业二年（606）两说并存，另有开皇七年、开皇十五/十六年等说。本文并列，不裁断。
2. **秀才科停废之年**（C）：《新唐书》系于永徽二年（651），另有贞观中废绝之说。
3. **唐代是否施行糊名**（C）：通说认为糊名定制于北宋；唐代局部施行的证据薄弱，待考。
4. **进士科加试诗赋的年代**（B）：调露二年（680）刘思立之请为通说，具体实施与反复情况待考。
5. **唐代进士总数**（B）：约六千余人是估计值，各家统计口径不同。
6. **明经与进士的录取比例**（B）：《新唐书》"千得百一二"为概略语，非精确统计。
7. **武举在唐前期的实际规模**（C）：史料零散，是否连年举行待考。
