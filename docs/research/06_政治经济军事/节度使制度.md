# 节度使制度

> 本文件讲"边帅怎样从'都督'变成'土皇帝'"。节度使是《隋唐行纪》后半段的核心矛盾：它不是突然出现的怪物，而是一套为解决边防问题而设计的制度，最后反噬了设计者。
>
> 标记：A 可靠 / B 有争议 / C 学界异说 / D 游戏推演。**"节度使"作为固定职衔始于景云二年（711）以后，隋代与贞观年间不得出现。**

## 一、制度起源：从总管到节度使

节度使不是凭空设置的，它是**缘边军事指挥权不断集中**的结果。

| 阶段 | 职名 | 性质 |
|---|---|---|
| 隋 | 总管 | 缘边、要冲之地统数州军事，事毕即罢 |
| 唐武德七年（624） | 都督 | 改总管为都督，置都督府，分上中下三等 |
| 贞观—高宗 | 都督 | 常加"使"衔，如安抚使、经略使，因事而设 |
| 景云二年（711） | **节度使** | 贺拔延嗣为凉州都督、充河西节度使，"节度使"名号自此始（B） |
| 开元年间 | 十节度经略使 | 定型为常设军区 |
| 天宝年间 | 十节度 | 兵力达四十九万，边帅兼领采访使，军政合一 |

**"节度"二字的本义**是"节制调度"——持节以节度诸军。它最初是一个**军事指挥权**，而非地方行政权。节度使之所以危险，正因为它后来把军、政、财、人四权集于一身。

> **时间纪律**：711 年之前，只能用"都督""总管""安抚使""经略使"，不得称"节度使"。时间轴校验规则第 2 条即指此。

## 二、开元十节度

天宝元年（742），天下置十节度经略使以备边。下表据《资治通鉴》卷二一五（A/B）：

| 节度 | 治所 | 统军/守捉 | 兵额 | 战略对象 |
|---|---|---|---|---|
| **安西** | 龟兹城 | 龟兹、焉耆、于阗、疏勒四镇 | 24,000 | 抚宁西域 |
| **北庭** | 北庭都护府 | 瀚海、天山、伊吾三军 | 20,000 | 防制突骑施、坚昆 |
| **河西** | 凉州 | 赤水、大斗、建康、宁寇、玉门、墨离、豆卢、新泉八军；张掖、交城、白亭三守捉 | 73,000 | 断隔吐蕃、突厥 |
| **朔方** | 灵州 | 经略、丰安、定远三军；三受降城；安北、单于二都护府 | 64,700 | 捍御突厥 |
| **河东** | 太原府 | 天兵、大同、横野、岢岚四军；云中守捉 | 55,000 | 与朔方犄角御突厥 |
| **范阳** | 幽州 | 经略、威武、清夷、静塞、恒阳、北平、高阳、唐兴、横海九军 | 91,400 | 临制奚、契丹 |
| **平卢** | 营州 | 平卢、卢龙二军；榆关守捉；安东都护府 | 37,500 | 镇抚室韦、靺鞨 |
| **陇右** | 鄯州 | 临洮、河源、白水、安人、振威、威戎、漠门、宁塞、积石、镇西十军；绥和、合川、平夷三守捉 | 75,000 | 备御吐蕃 |
| **剑南** | 益州 | 天宝、平戎、昆明、宁远、澄川、南江六军 | 30,900 | 西抗吐蕃，南抚蛮獠 |
| **岭南五府经略** | 广州 | 经略、清海二军；桂、容、邕、交四管 | 15,400 | 绥静夷獠 |
| **合计** | — | — | **约 490,000** | 马八万余匹 |

另有**长乐经略**（福州领，兵 1,500）、**东莱守捉**（莱州领，1,000）、**东牟守捉**（登州领，1,000），不在十节度之数。

> 上表数字出自《资治通鉴》卷二一五，属**纸面兵额**，未必与实有兵力相符，标 B。合计"凡镇兵四十九万"，为《通鉴》原文。

### 2.1 兵力分布的启示

| 观察 | 含义 |
|---|---|
| 范阳（91,400）为十镇之首 | 东北方向兵力最重，安禄山起兵的基础 |
| 河西（73,000）+ 陇右（75,000）= 148,000 | 西北两镇合计近十五万，为防御吐蕃主力 |
| 安西 + 北庭 = 44,000 | 西域驻军相对单薄，依赖本地兵与蕃兵 |
| 岭南仅 15,400 | 南方以羁縻为主，兵力最轻 |
| 关中、河南无节度使 | 中央腹地无重兵，外重内轻 |

**"外重内轻"是安史之乱的结构性原因**：天下精兵尽在边镇，中央禁军（彍骑）久已腐化，一旦边帅反叛，朝廷无兵可挡。

### 2.2 边费

《通鉴》同卷载：开元之前，每岁供边兵衣粮，费不过二百万；天宝之后，边将奏益兵浸多，"每岁用衣千二十万匹，粮百九十万斛，公私劳费，民始困苦矣"（A）。这组数字是理解天宝财政危机的钥匙。

## 三、运作机制：节度使的四权

| 权力 | 具体内容 | 途径 |
|---|---|---|
| **军权** | 统兵、练兵、调兵、辟置将校、便宜行事 | 节度使本职 |
| **政权** | 兼领所治州刺史或都督，掌民政 | 兼刺史/都督 |
| **财权** | 掌本地赋税、营田、支度，往往不上供 | 兼支度使、营田使 |
| **人事权** | 辟署幕僚、奏请属官 | 使府辟召 |
| **监察权** | 天宝年间多兼采访处置使 | 兼采访使 |

四权合一之后，节度使事实上成为**半独立的地方军政首长**。朝廷能控制的，只剩任免与调任两道关口。

## 四、采访使与节度使

- **开元二十一年（733）**，分天下为十五道，置**采访处置使**，以六条检察州县非法，属监察系统（《旧唐书》卷三八《地理志一》；A）。
- 采访使原本与节度使**互相牵制**：一个管军，一个管监察。
- 天宝年间，采访使多由节度使兼领，**监察权并入军权**，牵制机制失效（B）。

这一步是"节度使失控"的关键：不是朝廷没有制度，而是制度被兼任掏空了。

## 五、节度使与中央的矛盾

| 矛盾 | 表现 |
|---|---|
| 兵力 | 边镇四十九万 vs 中央禁军虚弱 |
| 财政 | 边费激增，中央财政被拖垮 |
| 入相 | 边帅有功者往往入朝为相，威胁宰执 |
| 人事 | 节度使久任不调，形成地方势力 |
| 族群 | 朝廷用胡人为边帅，又猜忌胡人 |

**李林甫的政策**：为杜绝边帅"入相"之路，李林甫主张用寒族、胡人为边帅，理由是"文臣为将，怯当矢石，不如用寒族胡人"（《资治通鉴》卷二一六；B）。这一政策直接为安禄山铺路——胡将无法入相，只能长期坐镇一方。

## 六、安禄山兼三镇

| 年份 | 事件 | 出处 | 级别 |
|---|---|---|---|
| 742 | 安禄山为平卢节度使 | 《资治通鉴》卷二一五 | A |
| 745 | 兼范阳节度使 | 《旧唐书》卷二〇〇上《安禄山传》 | A |
| 751 | 兼河东节度使 | 同上 | A/B |
| 754 | 一身兼三镇，"拥兵近二十万" | 《资治通鉴》卷二一七 | B |
| 755 | 以"奉密诏讨杨国忠"为名起兵于范阳 | 同上 | A |

三镇合计纸面兵力：范阳 91,400 + 平卢 37,500 + 河东 55,000 = **183,900**，与"近二十万"相合。这就是"以一镇之力不足以反，以三镇之力足以亡天下"的具体数字。

## 七、藩镇割据的起源

安史之乱后，藩镇割据的雏形出现，其机制有三：

1. **降将受封**：史朝义败亡前后，唐廷以安史降将为节度使，如田承嗣（魏博）、李怀仙（卢龙）、张忠志（成德，赐名李宝臣），是为"河朔三镇"。
2. **内地遍置方镇**：平叛过程中，内地亦普设节度使，"由是方镇相望于内地，朝廷不能制，而甘为姑息之政"（《文献通考》卷一五六引林氏；A/B）。
3. **财赋截留与世袭**：藩镇不上供、节度使父死子继，形成事实上的独立王国。

> **本作主线止于 763 年**，藩镇割据的完整形态（河朔三镇世袭、元和削藩）在此之后。游戏中只宜表现"割据的起点"：降将被授节、内地置镇、赋税不上供。

## 八、时代变化

| 阶段 | 边镇体制 | 关键 |
|---|---|---|
| 隋 581—618 | 总管、行军总管，事毕即罢 | 无固定军区 |
| 唐初—贞观 618—649 | 都督府；缘边置镇 | 府兵为主，边军为辅 |
| 高宗武周 649—705 | 都督、安抚使、经略使 | 边患增多，军权渐集中 |
| 开元 713—741 | 十节度定型（742 年正式列名） | 募兵制并行；节度使权力扩大 |
| 天宝 742—755 | 节度使兼采访使，四权合一 | 安禄山兼三镇；外重内轻 |
| 安史乱后 755—763 | 降将受节，内地置镇 | 藩镇割据起点 |

## 九、与百姓的关系

1. **边费转嫁**：天宝年间边军衣粮激增，最终由农户承担（和籴、加赋）。
2. **节度使辖区的赋税**：不上供中央，但地方负担未必减轻，军府、营田、杂税层层加码。
3. **兵源**：募兵之后，破产农民以当兵为生，军饷成为家庭唯一收入。
4. **战乱**：节度使一旦反叛，最先遭殃的是辖下与沿途百姓。安禄山起兵，河北州县"望风瓦解"。
5. **胡汉杂处**：边镇多蕃兵蕃将，民族关系复杂，既有融合也有冲突。

## 十、历史影响

1. **节度使制度是唐代由盛转衰的制度性原因**：它解决了边防效率问题，却制造了中央失控问题。
2. **"外重内轻"格局**成为中国政治史上的经典教训，宋代"强干弱枝"即针对此而设。
3. **藩镇割据**延续至五代，直至宋初才被终结。
4. **采访使并入节度使**的教训说明：监察权若与被监察对象合一，制度即形同虚设。

## 十一、可转化游戏任务

### 任务一：711 年的那道任命

- **背景**：景云二年，朝廷议置河西节度使，有大臣反对"边帅久任必生患"。
- **目标**：在朝议中支持或反对设置节度使，并陈述理由。
- **玩法**：朝堂辩论。玩家可选择"边防效率""中央控制""财政负担"三种论点，每种论点触发不同结局与后续剧情。
- **知识点**：节度使名号之始（711）；总管—都督—节度使的演变；设置初衷。
- **真实性说明**：711 年始置为 B；辩论内容为 D。

### 任务二：十镇点兵

- **背景**：天宝元年，兵部核对十节度兵额，发现范阳实兵多于簿籍。
- **目标**：查明多出的兵员从何而来（私募？蕃兵？虚报？）。
- **玩法**：数据核对 + 实地调查。玩家比对兵部簿籍、节度使奏报、军仓支出，找出异常。
- **知识点**：十节度兵额；纸面兵额与实际兵力的差距；边将"奏益兵"的动机。
- **真实性说明**：十镇兵额为 B；案件为 D。

### 任务三：采访使的两难

- **背景**：某采访使发现节度使虚报军功、截留赋税，但节度使正受皇帝宠信。
- **目标**：决定弹劾、密奏、还是与之合作。
- **玩法**：风险抉择 + 证据收集。玩家需在节度使辖区内秘密取证，每多问一人就多一分危险。
- **知识点**：采访使的监察职能；监察权与军权的冲突；天宝年间的政治生态。
- **真实性说明**：采访使制度为 A/B；案件为 D。

### 任务四：三镇之兵

- **背景**：天宝十四载，安禄山兼三镇，幕府中有人察觉异动。
- **目标**：以一个小吏的身份，判断"是否会反"，并决定是否上报。
- **玩法**：情报分析。玩家收集粮草调动、兵器打造、使者往来三类线索，做出判断；判断正确与否影响后续剧情分支。
- **知识点**：三镇合计兵力；起兵前的准备迹象；基层官员的困境。
- **真实性说明**：三镇兵力与起兵为 A/B；人物为虚构（D）。

### 任务五：降将受节（763）

- **背景**：安史之乱将平，朝廷议以降将为节度使，有人力谏"此养虎也"。
- **目标**：在"安抚"与"削权"之间提出方案，并预见后果。
- **玩法**：政策模拟。玩家可提出"留降将""分其地""调离"三种方案，每种方案导向不同的藩镇格局。
- **知识点**：河朔三镇的由来；藩镇割据的起点；"方镇相望于内地"。
- **真实性说明**：降将受节为 A/B；方案推演为 D。

## 争议与待考证

1. **"节度使"名号始置之年**（B）：景云二年（711）贺拔延嗣为河西节度使为通说，另有景云元年、先天年间等说。
2. **十节度兵力数字**（B）：出自《资治通鉴》卷二一五，属纸面兵额，与实有兵力可能有差距。
3. **安禄山兼三镇的时间**（B）：范阳 745、河东 751 为通说，具体月份与兼职形式有异说。
4. **安禄山起兵兵力**（B）：《通鉴》作十五万、号二十万，实际或有夸大。
5. **采访使与节度使合并的时间**（C）：天宝年间渐次合并，具体年份待考。
6. **藩镇割据的起点**（C）：有安史乱中、乱后受降、德宗建中诸说。
7. **"外重内轻"的量化程度**（C）：中央禁军与边镇兵力的对比，各家估算不同。
