# 赋税制度

> 本文件讲"一个农户一年要交多少粟、多少绢、出多少天工，以及这些数字怎样从县衙的账簿一路报到户部"。赋税是玩家最常撞见的"官府"面孔，也是游戏里最容易算错的部分。
>
> 标记：A 可靠 / B 有争议 / C 学界异说 / D 游戏推演。**所有税额数字一律标 B**——令文有明确数额，但折纳、加耗、地区差异使其实际负担与纸面数字不同。

## 一、制度起源

租庸调不是唐朝的原创，而是**北朝租调制与力役制度长期演化的结果**：

| 阶段 | 制度 | 要点 |
|---|---|---|
| 北魏 | 租调 | 一夫一妇帛一匹、粟二石 |
| 北齐 | 租调 | 丁男租二石、调绢一匹 |
| 隋 | 租调力役 | 一夫一妇租粟三石、调绢一匹（后减为二丈） |
| 唐武德七年（624） | **租庸调** | 租、调之外，明定"庸"——输绢代役 |
| 开元二十五年（737） | 重申 | 税额基本不变，执行已难 |

**"庸"是关键创新**：它把力役折算为绢帛，使国家获得稳定的实物收入，也使农民可以"以钱买闲"。这一制度萌芽于隋开皇十年（590）"民年五十，免役收庸"（《隋书》卷二四《食货志》；B）。

## 二、运作机制

### 2.1 租庸调的构成（唐制，数字标 B）

| 项目 | 数额 | 折算与说明 |
|---|---|---|
| **租** | 粟二石 | 丁男每岁输于州仓或县仓 |
| **调** | 绢二丈、绵三两 | 或纳布二丈五尺、麻三斤（不产绢之地） |
| **庸** | 役二十日 | 不役者，每日输绢三尺（布三尺七寸五分） |
| 闰月 | 加役二日 | 闰年增役 |
| 加役免调 | 加役二十五日免调，三十日租调皆免 | 通计正役不过五十日 |

（《新唐书》卷五一《食货志一》、《唐令拾遗》所辑赋役令；B）

> **注意单位**：绢一匹 = 四丈，二丈为半匹。游戏里若写"调绢二匹"，即错了一倍。

### 2.2 隋代赋役

| 项目 | 隋制 | 级别 |
|---|---|---|
| 租 | 一夫一妇粟三石；单丁及仆隶减半 | B |
| 调 | 绢一匹（四丈）、绵三两；开皇三年减为二丈 | B |
| 役 | 岁役日数史料记载不一，有三十日、二十日两说 | C |
| 免役收庸 | 开皇十年（590），年五十者免役，收庸 | B |
| 丁年 | 十八岁以上为丁，六十为老 | B |

> 隋制与唐制最大的不同：**隋无"庸"的普遍化**（仅五十以上许收庸），唐则把庸变成人人可用的常制。

### 2.3 户税与地税

租庸调之外，唐前期另有两项重要税收，后来成为两税法的骨架：

| 税目 | 计税依据 | 用途 | 级别 |
|---|---|---|---|
| **户税** | 按户等（九等）征钱 | 官俸、传驿、杂支 | B |
| **地税** | 按亩征粟（源于义仓税，亩二升） | 义仓储备、赈济 | B |

户税在唐代前期比重不大，安史乱后迅速膨胀，大历四年（769）有一次重要整顿（超出主线，作背景）。地税则因按亩计征、不随丁口变动，成为乱世中最可靠的税源。

### 2.4 色役与资课

**色役**是"以身份充任的特定差役"，如品子、勋官、亲事、帐内、白直、执衣、防阁、庶仆、门夫、烽子等。色役可以**纳资代役**，所纳之资称"**资课**"（《唐六典》卷三；B）。

色役的特点是**按身份、按户等分配**，而非按丁。官宦子弟多充"品子""亲事"，名义上是服役，实际是入仕的跳板。

### 2.5 杂徭

地方性的临时差科，如修渠、筑城、运粮、迎送。杂徭不入国家正税，由州县长官"差科"，因而最容易滥征，也是民怨的主要来源（B）。

## 三、征收流程与账簿

```
户部度支：编制年度"支度国用"计划，分配税额到州
   ↓
州司：拆分到县，核定应输数额与期限
   ↓
县司：据户籍造"租庸调簿""差科簿"
   ↓
里正：按簿催驱各户
   ↓
农户：输粟入州仓/县仓；输绢入州库
   ↓
仓吏、库吏：验收、给"抄"（收据）、记帐
   ↓
县造帐申州，州申户部；比部勾覆
```

**四本账，各有其时**：

| 账簿 | 编制者 | 周期 | 作用 |
|---|---|---|---|
| 手实 | 户主自报 | 每年 | 申报人口、田亩 |
| 计帐 | 县司 | 每年一造 | 年度赋役预算底册 |
| 户籍 | 县司 | 三年一造 | 授田、征税、征兵的总依据 |
| 差科簿 | 县司 | 临时 | 差役分派名单 |

（《唐会要》卷八五《籍帐》；B）

**折纳**是流程中最易生弊的一环：令文规定纳粟，实际可折绢、折钱；折算比例由地方按市价定，官吏上下其手，农户实际负担可翻倍。

**加耗**则是明文附加：为弥补运输、仓储损耗，征收时加收一定比例，比例各州不同（B）。

## 四、时代变化

| 阶段 | 税制状况 | 关键变化 |
|---|---|---|
| 隋 581—618 | 租调力役，税率较轻但役重 | 开皇三年减调；开皇十年免役收庸；大业年间滥役 |
| 唐初—贞观 618—649 | 租庸调确立，税率较宽 | 624 武德令；贞观年间"斗米三四钱"，负担感轻 |
| 高宗武周 649—705 | 税额外加征渐多，逃户增加 | 户税、地税比重上升；"括户"开始 |
| 开元 713—741 | 租庸调名义犹存，实际难行 | 721 宇文融括户；户税地税扩大；和籴兴起 |
| 天宝 742—755 | 横征暴敛，"中外嗟怨" | 王鉷"岁贡额外钱帛百亿万"（《资治通鉴》卷二一五；A）；戍边者租庸并征三十年 |
| 安史乱后 755—763 | 税制崩坏，地方截留 | 758 榷盐；率贷、括商；户税地税成为主税 |

> **天宝十四载前后的一个真实细节**：《资治通鉴》卷二一五载，旧制戍边者免租庸、六岁而更，边将隐瞒死亡不除籍，王鉷按籍追征，"有并征三十年者，民无所诉"。这是极好的剧情素材（A）。

## 五、商税与盐铁（背景）

- **商税**：唐前期关市之征较轻，主要有市肆交易税、入市税。安史乱起，军费浩大，始有"率贷"（按资产比例借钱）、"括商"（征商人之财）等非常之征（B）。
- **盐铁**：**乾元元年（758）**，第五琦行榷盐法，就山海井灶收榷其盐，官自出粜，斗加时价百钱（B）。宝应元年（762）刘晏接掌，改革盐法，为唐后期财政支柱——**已在主线末端，只可作尾声**。
- 茶税、酒榷等，均在建中以后，超出主线。

---

## 六、两税法：只作背景（780）

建中元年（780），杨炎奏行两税法：量出制入；户税与地税并行；夏秋两征；"户无主客，以见居为簿；人无丁中，以贫富为差"。

**它不是本作时间范围内的制度**（763 年主线已止）。游戏中只能以"某老吏预言"或"知识卡"形式出现，且必须明确标注年代为 780。

---

## 七、与百姓的关系

1. **税是按丁收的，不是按亩收的**：家中男丁多，税就多；授田不足，税不减。这是唐代农户"分户""逃户""出家"的根本动因。
2. **庸给了农民"以绢买时间"的选择**：一个壮劳力在农忙时节宁可输绢三尺而不去服役，这笔账在游戏里可以做成一个真实的抉择。
3. **折纳与加耗是隐形的第二重税**：纸面二石，实缴可能三石。
4. **催驱的是里正**：里正既是乡里领袖，又是国家代理人，这个双重身份是最好的 NPC 设定。

---

## 八、历史影响

1. **租庸调的"以丁为本"**，把人口登记推到极致，也使户籍制度成为国家能力的核心指标。
2. **庸的普遍化**，是中国赋役史上"力役向货币/实物转化"的关键一步，为两税法的"以资产为宗"铺路。
3. **户税与地税的成长**，在租庸调瓦解后接管了国家财政，构成两税法的直接前身。
4. **色役与资课**的发达，说明唐前期已存在相当规模的"货币化"财政操作，不能简单视为自然经济。

## 九、可转化游戏任务

### 任务一：一石粟的旅程

- **背景**：秋收后，农户须在限期内把二石粟送到州仓，途中遇雨、遇盗、遇斗级刁难。
- **目标**：把粟如数入库，拿到"抄"（收据）。
- **玩法**：运输管理 + 事件抉择。每遇一次意外，玩家需在"绕路""雇人""弃粮"间选择，最终入库数量决定任务评价。
- **知识点**：租的输纳流程；仓吏验收；"抄"的作用；加耗与折纳。
- **真实性说明**：输纳流程为 A/B；具体事件为 D。

### 任务二：庸与不庸

- **背景**：农忙将至，县司征役二十日修渠。农户可选择亲往，或输绢六丈（三尺 × 二十日）。
- **目标**：在"误农时"与"耗绢帛"之间做出最优选择。
- **玩法**：数值抉择。玩家计算家中存绢、田里收成、雇工市价，选择亲役、输庸或部分输庸；不同选择触发不同秋收结果。
- **知识点**：庸的折算率（日绢三尺）；庸的适用条件；农时与力役的冲突。
- **真实性说明**：折算率为 B；数值模型为 D。

### 任务三：折纳的猫腻

- **背景**：县司公告"今岁折纳，一石粟折绢一匹半"，市价实为一匹。
- **目标**：查出折纳比例被谁改动，并决定是否上告。
- **玩法**：账目比对 + 风险抉择。玩家对比户部符文、州司牒、县司榜文三份文书，找出被篡改的一处。
- **知识点**：折纳制度；文书三级流转；上告的法律风险。
- **真实性说明**：折纳为 B；案件为 D。

### 任务四：貌阅与逃户

- **背景**：某里正报"本里无逃户"，但县司计帐显示该里课丁数三年未变，而实际耕种的田亩在减少。
- **目标**：查明逃户去向（寺院？庄园？他州？），并估算税额缺口。
- **玩法**：调查 + 推算。玩家走访寺院、庄园、邻县，拼出逃户路线图；最终填写一份"括户申牒"。
- **知识点**：逃户与客户；貌阅、团貌；开元括户的背景。
- **真实性说明**：逃户问题为 A/B；案件为 D。

### 任务五：榷盐之始（758 年后）

- **背景**：乾元元年行榷盐法，盐价骤涨，私盐贩子出现。
- **目标**：以县尉身份查缉私盐，同时面对"官盐太贵、百姓吃不起"的现实。
- **玩法**：追捕 + 道德困境。玩家可严查、可睁一眼闭一眼、可上书请减盐价；三种选择导向不同民望与考课结果。
- **知识点**：758 年第五琦榷盐；盐利与军费；私盐的成因。
- **真实性说明**：榷盐始于 758 年，B；具体案件为 D。

## 争议与待考证

1. **隋代岁役日数**（C）：有三十日、二十日两说，史料记载不一。
2. **租庸调额的具体数字**（B）：粟二石、绢二丈、绵三两、役二十日为通说，但《唐令拾遗》所辑与两《唐书》志文略有异文。
3. **"庸"的起源**（C）：开皇十年"免役收庸"是萌芽，但唐初"庸"是否为常制，学界有不同看法。
4. **户税的税率与户等划分**（C）：唐代户税按九等户征钱，但各等具体钱数史料零散，未逐条核对。
5. **地税"亩二升"的施行范围**（B）：是否全国一律，抑或因地制宜，待考。
6. **色役的种类与资课标准**（B）：名目繁多，各时期不同，本文仅列常见者。
7. **加耗比例**（C）：各州不同，未见统一令文。
