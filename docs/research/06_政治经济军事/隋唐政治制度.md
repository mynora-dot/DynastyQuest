## 一、制度起源：从北周六官到隋唐三省

隋唐官制的直系祖先是**北周的六官制度**与**北齐的三省制度**。北周仿《周礼》设六官，形式古奥而运转不便；北齐则已有中书出令、门下审议、尚书执行的分工雏形。隋文帝代周，命高颎、苏威等修定律令，把北齐的三省框架与中央集权需要嫁接起来，形成"三省六部"的骨架（《隋书》卷二八《百官志下》；A/B）。

关键的时间点：

| 年份 | 事件 | 出处 | 级别 |
|---|---|---|---|
| 581 | 隋受周禅，置尚书、门下、内史三省 | 《隋书》卷二八《百官志下》 | A |
| 583 | 开皇三年，罢天下诸郡，行州—县二级 | 《隋书》卷一《高祖纪上》 | A |
| 583 | 改都官为刑部、度支为民部 | 《隋书》卷二八《百官志下》 | B |
| 607 | 大业三年，改州为郡，行郡—县二级 | 《隋书》卷三《炀帝纪上》 | A |
| 618 | 唐武德元年，置三省六部，改郡为州 | 《旧唐书》卷一《高祖纪》 | A |
| 649 | 贞观二十三年，避太宗讳，改民部为户部 | 《旧唐书》卷四三《职官志二》 | B |

**避讳是隋唐官制的第一道陷阱**：

| 正式官名 | 隋代叫法 | 原因 |
|---|---|---|
| 中书省 | **内史省** | 隋避杨忠讳，"中"改"内" |
| 中书令 | **内史令** | 同上 |
| 侍中 | **纳言** | 避"中"字 |
| 御史中丞 | **治书侍御史** | 避"中"字 |
| 民部 | 民部（唐贞观末改户部） | 唐避李世民讳 |

> **游戏处理**：隋代场景里出现"中书省""侍中""户部"，即为硬伤。可让老吏故意说错、被上官纠正，作为一场极小的知识考核。

## 二、运作机制

### 2.1 三省分工：出令—审驳—执行

| 省 | 长官（唐） | 核心职能 | 关键权力 |
|---|---|---|---|
| 中书省 | 中书令（二人） | 草拟诏敕、进画 | 出令权；军国大事先由中书取旨 |
| 门下省 | 侍中（二人） | 审议诏敕、封驳 | **封驳权**——可以"涂归"退回 |
| 尚书省 | 尚书令（虚置）、左右仆射 | 总领六部、执行 | 行政执行权、人事铨选 |

唐初尚书令因太宗曾任而**长期虚置**，左右仆射成为实际长官；至开元以后，仆射不带"同中书门下平章事"者即非宰相（《新唐书》卷四六《百官志一》；B）。这是"三省长官即宰相"到"差遣为使职宰相"的关键转折。

诏敕流转的实际链条：

```
皇帝旨意 → 中书省草拟（中书舍人"五花判事"，各执一见）
        → 门下省审议（给事中读、侍郎省、侍中审）
        → 有异议：涂归封还（封驳）
        → 无异议：署"制可" → 尚书省 → 六部 → 州 → 县
```

### 2.2 六部二十四司

唐制每部四司，共二十四司。此表据《唐六典》卷二至卷七的篇目次序（A）：

| 部 | 四司 | 职掌要点 |
|---|---|---|
| 吏部 | 吏部、司封、司勋、考功 | 文选、封爵、勋级、考课 |
| 户部 | 户部、度支、金部、仓部 | 户口、财计、钱帛、仓廪 |
| 礼部 | 礼部、祠部、膳部、主客 | 贡举、祭祀、宴飨、蕃客 |
| 兵部 | 兵部、职方、驾部、库部 | 武选、地图、马政、兵器 |
| 刑部 | 刑部、都官、比部、司门 | 刑法、徒隶、勾覆、门禁 |
| 工部 | 工部、屯田、虞部、水部 | 营造、屯田、山泽、水利 |

> 隋代六部下的曹司数目前后有变（隋初曹数较多，后经省并），至唐方定型为二十四司。《隋书》卷二八《百官志下》记隋六曹属官，但**曹司的确切数目与名称学界仍有分歧，标 C**。游戏里写隋代衙门，宜用"某部某曹"这类泛称，不要硬报二十四司。

### 2.3 政事堂与宰相制度

唐初，宰相于**门下省**政事堂合议国政。其后迁至中书省。**开元十一年（723）**，张说奏改政事堂为"**中书门下**"，列吏、枢机、兵、户、刑礼五房于其后，宰相合议由此从"临时会议"变成"固定机构"（《旧唐书》卷四三《职官志二》；B）。

宰相衔的演变：

| 阶段 | 宰相身份 | 说明 |
|---|---|---|
| 唐初 | 三省长官自然为相 | 人数少，权力集中 |
| 贞观—高宗 | 加"同中书门下三品""同中书门下平章事" | 以他官参预机务，宰相群体扩大 |
| 723 后 | 中书门下体制 | 宰相固定于中书门下，三省渐成执行机构 |
| 天宝 | 左相（侍中）、右相（中书令） | 天宝元年改侍中为左相、中书令为右相 |

"同中书门下平章事"作为使职差遣**定型于中晚唐**，唐初不得滥用（见时间轴校验规则第 2 条）。

### 2.4 九寺五监：事务官系统

三省六部是"政务官"，九寺五监是"事务官"。据《唐六典》卷一三至卷二三的编排（A）：

| 九寺 | 职掌 | 五监 | 职掌 |
|---|---|---|---|
| 太常、光禄、卫尉 | 礼乐、膳食、仪仗 | 国子、少府 | 学校、宫廷手工业与铸钱 |
| 宗正、太仆、大理 | 谱籍、牧政、审判 | 将作、军器 | 营造、甲弩制造 |
| 鸿胪、司农、太府 | 蕃客、仓廪、钱帛市易 | 都水 | 水利津梁 |

太府寺下辖"两京诸市署"与"平准署"，直接管市场——这是写长安西市场景最该用的衙门（详见 `货币与商业.md`）。

### 2.5 御史台

唐御史台设大夫一人、中丞二人，分三院：**台院**（侍御史，纠弹百官、推鞫案件）、**殿院**（殿中侍御史，朝会仪序、京城纠察）、**察院**（监察御史，分道巡按州县）（《新唐书》卷四八《百官志三》；A/B）。巡按御史是极好的剧情装置：品级不高却能直达天听，足以让县令睡不着觉。

### 2.6 地方层级

| 时期 | 层级 | 备注 |
|---|---|---|
| 隋初 | 州—郡—县 | 三级 |
| 583 后 | 州—县 | 罢郡，二级 |
| 607 后 | 郡—县 | 改州为郡 |
| 唐武德 | 州—县 | 复州 |
| 唐 | 州（上/中/下）、县（京/畿/上/中/下） | 按户口定等 |
| 742—758 | 郡—县 | 天宝改州为郡、刺史为太守 |
| 758 后 | 州—县 | 乾元元年复 |

**道**是监察区，不是行政区。贞观元年（627）分天下为十道，开元二十一年（733）分为十五道，置采访处置使（《旧唐书》卷三八《地理志一》；A）。

**都督府**：隋称总管，唐武德七年（624）改总管为都督，置于缘边及要冲之地，分上、中、下三等，统数州兵马（B）。都督府是"节度使"的前身，详见 `节度使制度.md`。

### 2.7 品级与俸禄

唐职事官九品，每品分正从，四品以下又分上下，共**三十阶**。俸禄由四块构成（B）：禄米（按品给粟）、职分田（收租充俸，离任移交）、永业田（可传子孙）、月俸料钱（兼给防阁、庶仆等力课）。隋代另有**公廨钱**（官府放贷取息充公费）与职分田。具体数额各朝屡改，本文件不列石数、钱数；游戏若需数字，请另立"物价与俸禄"专表并全部标 B。

### 2.8 文书制度

唐制"上之逮下"六种：制、敕、册、令、教、符；"下之达上"六种：表、状、笺、启、辞、牒（《唐六典》卷一；B）。

| 文书 | 方向 | 用途 |
|---|---|---|
| 制/诏、敕 | 皇帝→天下/有司 | 大典礼用制诏，日常政务用敕 |
| 符、牒 | 上级→下级 | 尚书省下州、州下县用符；非直属用牒 |
| 关/移 | 平行 | 平级机构往来 |
| 奏抄、状 | 下→上 | 尚书省上奏；陈事谢恩 |

**"判"**是唐代文官的基本功：收到牒文，须在末尾写出处理意见并署名，称"判"；吏部铨选考身、言、书、判，判居其一。这是极好的玩法内核——**批公文**。

### 2.9 户籍：貌阅与团貌

- **大索貌阅**：开皇三年（583），高颎建议"输籍定样"，隋文帝下令核实户口，验貌以定老小，"计帐进四十四万三千丁，新附一百六十四万一千五百口"（《隋书》卷二四《食货志》；B，数字或有夸饰）。
- **团貌**：唐制，州县每年对照人丁形貌核实年龄；户籍**三年一造**，计帐**每年一造**（《唐会要》卷八五《籍帐》；B）。户籍一式三份，县、州、户部各存其一，**县留原件**。

### 2.10 考课

唐考课以"**四善二十七最**"为标准。四善为德义有闻、清慎明著、公平可称、恪勤匪懈；二十七最按部门分列。等第九等，每年一小考，三至四年一大考，考状随考簿上报（《新唐书》卷四六《百官志一》；B）。

## 三、时代变化（分阶段）

| 阶段 | 中枢 | 地方 | 关键变化 |
|---|---|---|---|
| 隋 581—618 | 内史省—门下省—尚书省；三省长官常由重臣兼领，实际决策集中在内廷 | 州—县（583 后）；607 改郡 | 废九品中正、罢郡、定六部；**无"中书省"之名** |
| 唐初—贞观 618—649 | 三省分工明确化；政事堂议政；门下封驳强化 | 州—县；627 分十道 | 尚书令虚置；民部未改户部；《贞观令》定型 |
| 高宗武周 649—705 | 宰相群体扩大，"同三品""同平章事"渐多；政事堂仍在门下 | 州—县；置都督府 | 649 改民部为户部；683 前后政事堂迁中书 |
| 开元 713—741 | **723 政事堂改中书门下**；五房分曹 | 733 分十五道，置采访处置使 | 使职差遣兴起，"旧官充位而已" |
| 天宝 742—755 | 左相/右相；李林甫、杨国忠专权，政事决于私家 | 742 改州为郡、刺史为太守 | 节度使兼采访使，中央对边镇失控 |
| 安史乱后 755—763 | 中书门下体制延续；使职进一步膨胀 | 758 复州；内地遍置节度使 | 藩镇截留赋税，中央政令不出关 |

## 四、与百姓的关系

三省六部看似离百姓极远，实则一个农户一生要撞上它至少四次：

1. **成丁**：户籍上的年龄决定他是"中"还是"丁"。天宝三载（744）"令百姓十八为中，二十三成丁"，一夜之间无数人的户口年龄被改写（《资治通鉴》卷二一五；A）。
2. **授田与纳税**：户部—州—县的田籍决定占田亩数；租庸调由县司征收、里正催驱，账簿直报户部（见 `农业与土地制度.md`、`赋税制度.md`）。
3. **诉讼**：县→州→大理寺，或击登闻鼓。地方官"判"的好坏直接决定他的生死。
4. **差役与兵役**：户等定差役，丁籍定是否被"点"为府兵。

对百姓而言，"制度"就是**每年上门的那张纸、那个斗、那声催**。

## 五、历史影响

三省制把决策、审议、执行分开，并以封驳权对皇权构成有限制约，宋之"二府三司"、明之内阁六部皆可溯源。政事堂→中书门下使"宰相合议"机构化，三省渐虚化为执行机关。使职差遣以临时之职架空固定官制，效率提高而权责脱节，终酿藩镇之祸。科举与考课结合，则使"读书—做官—升迁"成为可计算的路径（见 `科举制度.md`）。

## 六、可转化游戏任务

### 任务一：涂归

- **背景**：贞观年间，中书省草拟一道加征关东某州租米的敕书，门下省给事中认为与《贞观令》抵牾。
- **目标**：在三日之内，找出敕书与令文的冲突条款，决定"封驳"还是"署可"。
- **玩法**：文书比对解谜。玩家翻阅《令》文残卷、敕书草稿、户部计帐，逐条勾出矛盾；最终选择"涂归"（退回）或"署可"，两条分支引出不同后果。
- **知识点**：门下省的封驳权；诏敕流转链条；"制可"的法律效力。
- **真实性说明**：封驳制度见《新唐书》卷四七《百官志二》，属 A；具体案例为设计推演（D），不指涉真实人物。

### 任务二：团貌

- **背景**：开元年间某县团貌，里正报上一批"未成丁"的少年，其中数人形貌明显不符。
- **目标**：查明是户籍讹误、里正受贿，还是为逃避府兵而谎报年龄。
- **玩法**：对话取证 + 户籍册交叉核对 + 现场"验貌"。玩家要把三份名册（县籍、计帐、里正手实）对齐，找出被改动的年份。
- **知识点**：团貌、貌阅、"三年一造户籍、每年一造计帐"；成丁年龄与赋役、兵役的联动。
- **真实性说明**：团貌与籍帐制度见《唐会要》卷八五，B；具体案件为 D。

### 任务三：批一纸判

- **背景**：玩家新任县尉，案头积压十份牒文，须在散值前批完。
- **目标**：按"身言书判"的标准写出十份判词，且不能与律令冲突。
- **玩法**：文书填写小游戏。每份牒给出案情与律条，玩家选择援引条款、拟处理意见、署名。判错会引发上司驳正，判对累积"考课"分数。
- **知识点**：唐代"判"的文体与功能；四善二十七最；吏部铨选考判。
- **真实性说明**：判与考课制度为 A/B；判词内容为模拟写作（D），不抄录真实判文。

### 任务四：政事堂的一炷香

- **背景**：开元十一年（723）政事堂改为中书门下，五房初立，旧吏不识新规，公文在廊下打转。
- **目标**：三天内让一份河北水灾赈济敕书走完全程。
- **玩法**：流程调度。玩家扮主书，安排五房分曹、催办、补签，处理"门下要复核""户部说无粮""兵部要调驿马"三类扯皮。
- **知识点**：723 年政事堂改制；五房分工；使职与旧官制的摩擦。
- **真实性说明**：改制年份见《旧唐书》卷四三《职官志二》，B；五房运作细节史料有限，玩法为 D。

## 争议与待考证

1. **隋代六部曹司数目**（C）：隋初曹数、开皇三年省并后的数目、《隋书·百官志》的记载是否完整，学界有不同理解。本文只写"六部"骨架，不写二十四司。
2. **政事堂迁中书省之年**（C）：有永淳元年（682）裴炎迁、弘道元年（683）两说；本文取"683 前后"，标 B。
3. **"同中书门下平章事"入衔之年**（C）：有贞观八年（634）李靖"平章事"、永淳元年（682）郭待举等两说，性质不同（前者为特命，后者为常制）。
4. **折冲府与地方官品级的具体对应**（B）：《唐六典》与两《唐书》志间有出入，未逐条核对。
5. **"四善二十七最"的二十七最条目**（B）：各书所载略有异文，未逐条比对。
6. **唐前期"道"的性质**（C）：监察区抑或准行政区，学界长期争论。
