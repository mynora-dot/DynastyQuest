# 交通工具

> **核心结论**：隋唐是"**马车—牛车—驴—马—船**"并行的时代，**轿子在隋代极少、唐前期也主要用于宫廷与老病**，肩舆普及要到唐中后期。牛车在唐初是贵族女性的"体面座驾"，不是农具；马是身份与军力的象征。所有速度数据必须来自《公式令》一类的制度规定，不能凭想象。
>
> 可信度标记：A 可靠 / B 细节有争议 / C 学界异说 / D 游戏推演。

## 一、马车

| 项目 | 内容 |
|---|---|
| 形制 | **双辕**（一辕驾一马，或两辕驾两马），木制车厢，车轮有辐（约18—30辐），轮径约1.2—1.4米（B） |
| 类型 | **轺车**（轻便、有伞盖、无封闭车厢，速快）；**辎车/帷车**（车厢封闭，有帷幔，载人载物）；**栈车**（粗木，载货） |
| 轨距 | **1.3米多**（【考古】大明宫玄武门石门槛车辙沟实测），可据此统一所有车辆的轮距 |
| 载重 | 乘用车2—4人；货车约300—500公斤（B） |
| 速度 | 《公式令》行程：**重车日三十里、空车日五十里**（B） |
| 色彩 | 车厢木本色或黑漆，贵族车朱漆、饰铜；帷幔青、绯 |

**画法**：车轮必须与轨距一致；车厢侧面画"横木栏杆"或"帷幔"，车辕前伸两根。上坡时车辕上翘。

---

## 二、牛车

| 项目 | 内容 |
|---|---|
| 形制 | 牛驾，车厢**封闭如小屋**，顶为圆拱或平顶，两侧开窗，前有门帘；轮大、厢高 |
| 使用者 | **唐初贵族女性**、老臣、妇女出行；宫廷用车也多用牛 |
| 装饰 | 高级牛车"饰以金银"，帷幔用绫罗，牛角挂铃 |
| 速度 | 约日行30—40里（B）；比马车慢而稳 |
| 期别 | Ⅱ—Ⅲ期最盛，Ⅳ期渐被骑马与肩舆分流，Ⅴ期仍常见于民间 |

**画法**：牛要画成**黄牛/水牛**，肩峰明显，步伐慢；车厢做"活动小屋"，窗帘可开合。这是"贵妇出行"场景的标志性道具。

---

## 三、驴与骡

- **骑驴**：官员、士人、僧道、妇女均可；唐初马缺，官员有骑驴上朝者（B）。
- **驴车**：小型货车，城乡短途运输主力。
- **骡**：驴马杂交，耐力好，用于长途货运。
- 速度：《公式令》"步及驴日五十里"（B）。
- 画法：驴体小（肩高约1.2米），耳长，步伐碎快；驮架两侧挂口袋。

---

## 四、骆驼

| 项目 | 内容 |
|---|---|
| 形制 | 双峰驼，峰间架驮架，两侧挂囊袋、水囊、毡毯 |
| 使用者 | 西域商队、丝路使团、军队辎重 |
| 载重 | 约150—200公斤（B） |
| 速度 | 日行30—40里（B） |
| 图像 | 三彩骆驼载乐俑、骆驼胡人俑（陕历博、国博） |

**画法**：骆驼是"西域感"的最强符号——长颈、双峰、厚掌、毛色沙黄（#C9A26B），驮架上挂红蓝织物。行走帧要慢、有起伏。

---

## 五、轿与肩舆

| 期 | 情况 |
|---|---|
| Ⅰ隋 | **极少**；《隋书》礼仪中肩舆限于宫廷、老病 |
| Ⅱ—Ⅲ | **步辇**（帝王乘坐，阎立本《步辇图》【考古·绘画】可证）；官员偶用"檐子" |
| Ⅳ | 民间"檐子"渐多，但仍以车马为主 |
| Ⅴ及以后 | 肩舆、轿子增多，宋代才真正普及 |

**画法**：步辇为**平板＋四柱＋顶盖**，由宫人抬；不要画成明清封闭式轿厢。

## 六、骑马与马具

| 部件 | 形制 | 画法 |
|---|---|---|
| **马镫** | 金属环镫，双镫，革带悬挂 | 必须有；无镫即时代错误 |
| 鞍 | 木鞍桥，前桥高、后桥低，包皮革 | 鞍桥可包金银（贵族） |
| 鞯 | 鞍下垫毯，垂于马腹两侧 | 花纹毯，最好看的一块 |
| **障泥** | 马腹两侧垂下的挡泥片，皮质或织锦 | 长及马膝，行走时摆动 |
| 辔头/衔镳 | 革制，镳为金属 | 缰绳一根 |
| 杏叶 | 马具上的杏形铜饰 | 高级马具的闪光点 |
| 马尾 | 多扎起或打结 | 战马扎尾 |

**马体**：唐马肩高约1.4—1.5米，头小颈粗、四肢细长、臀圆，即"昭陵六骏"体型。

**速度**：乘马日行70里（《公式令》，B）；驿马急递可日行300里，最快500里（B，属军情特例）。

## 七、船只

| 船型 | 形制 | 用途 | 期别 |
|---|---|---|---|
| **漕船** | 平底、方头、宽舱，设桅与橹 | 运河运粮 | 全程，Ⅱ期后大盛 |
| 客船 | 有篷舱，两侧开窗 | 载客 | 全程 |
| **楼船** | 多层甲板，设女墙、拍竿 | 水战 | 全程 |
| **龙舟** | 隋炀帝所乘，四重，高45尺、长200尺（《隋书》系年，B） | 巡幸 | Ⅰ期 |
| 平底海船 | 平底、水密舱、多桅 | 近海、登莱航线 | Ⅲ—Ⅳ期 |
| 篷船（江南） | 竹篷、小舟 | 内河捕鱼、摆渡 | 全程；**"乌篷船"之名晚出，形制可参考，名称勿用** |
| 羊皮筏 | 羊皮囊扎筏 | 黄河上游渡河 | 待考证（C） |

**载重**：漕船常见载重约数百石（B，各航线差异大）；内河小船1—3吨。

**速度**：《公式令》水行**溯流日三十里、顺流日五十里**（B）。运河过堰、过闸需转运，实际更慢。

## 八、驿站车马

| 项目 | 内容 |
|---|---|
| 驿距 | 三十里一驿（《唐六典》卷五），天下驿1639所（B） |
| 配置 | 驿马、驿驴、传车；水驿配船 |
| 凭证 | 传符、驿券；无券不得乘驿 |
| 速度 | 常行日4—6驿（120—180里）；急递300里/日（B） |
| 画法 | 驿院内有马厩、拴马桩、饮马槽、草料堆；驿马挂铃 |

## 九、道路

| 类型 | 形制 | 备注 |
|---|---|---|

## 十、纤夫拉纤

运河上行、过堰时以人力拉纤。纤夫十余人至数十人一队，绳系桅杆或船首，赤足、短褐、号子。**画法**：身体前倾30度，绳绷直，脚步同步；可做"拉纤"小游戏（节奏点击）。

## 来源核验与时间一致性自检

1. 轿子/肩舆在Ⅰ—Ⅱ期只能作宫廷、老病特例，不得作为民间日常出行。
2. 马镫必须有，且为双镫金属环。
3. 车轨统一按1.3米余，与玄武门车辙一致。
4. 龙舟仅Ⅰ期隋炀帝场景可用。
5. "乌篷船"为后世俗称，文本中避免作为唐代船名。
6. 速度只引用《公式令》，其余标"待考证"或D。
7. 未编造文物编号与页码。
