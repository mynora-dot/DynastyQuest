# 宗教与民俗

> **核心结论**：唐代宗教是"**佛道并尊 + 三夷教并存 + 民间信仰打底**"的多层结构。三夷教传入时间必须精确：**祆教**唐初置祠（621），**景教**贞观九年（635）阿罗本入长安，**摩尼教**延载元年（694）传入。民俗方面，**上元灯节、寒食清明、端午竞渡、七夕乞巧**是最有画面感的四大节令；**中秋赏月**在唐中期才成形，**月饼尚未出现**。
>
> 可信度标记：A 可靠 / B 细节有争议 / C 学界异说 / D 游戏推演。

## 一、佛教

| 面向 | 内容 |
|---|---|
| 寺院经济 | 田庄、碾硙、邸店、借贷（无尽藏）；寺院兼营旅舍、仓贮 |
| 僧籍 | 度僧须得**祠部牒**（度牒），私度违法；僧尼免课役，故度牒有价 |
| 法会 | 无遮大会、盂兰盆会（七月十五）、迎佛骨（法门寺） |
| **俗讲** | 僧人于寺院对俗众讲经，讲唱结合，有押座文、讲经文 |
| **变文** | 敦煌出土《降魔变文》《目连变文》《伍子胥变文》等，韵散相间，是后世说唱之源 |
| 宗派 | 天台、三论、法相（玄奘）、华严（法藏）、禅（东山法门）、律、净土 |
| 名僧 | 玄奘（602—664）、道宣、法藏、神会、鉴真（688—763） |
| 图像 | 敦煌壁画、彩塑；长安大慈恩寺大雁塔（652） |

**画法**：寺院是"公共空间"——戏场、俗讲、庙会都在寺中。大殿前设香炉、幡幢；俗讲设高座、经案。

## 二、道教

| 面向 | 内容 |
|---|---|
| 国教地位 | 李唐尊老子为始祖；乾封元年（666）尊老子为"太上玄元皇帝"（A） |
| 宫观 | 长安太清宫、玄都观、昊天观；洛阳上清宫；天下州立玄元皇帝庙 |

| 修炼 | 服气、导引、辟谷、炼丹（金丹、外丹） |

| 女冠 | 公主入道成风（如金仙公主、玉真公主） |

**画法**：道观主殿供老君像，加八卦纹、鹤、青牛；炼丹房有丹炉、朱砂、铅汞罐。

## 三、三夷教（时间务必精确）

| 宗教 | 传入/建制时间 | 长安据点 | 依据 |
|---|---|---|---|
| **祆教（拜火教）** | 北魏已入；唐**武德四年（621）**置祆祠 | 布政坊、醴泉坊、普宁坊胡祆祠；设萨宝府 | 《唐会要》（A/B） |
| **景教（基督教聂斯托利派）** | **贞观九年（635）**阿罗本至长安，太宗令于义宁坊造大秦寺 | 义宁坊大秦寺 | 《大秦景教流行中国碑》（781年立，A） |
| **摩尼教** | **延载元年（694）**波斯人拂多诞持《二宗经》来朝 | 长安、洛阳 | 《佛祖统纪》（A/B）；开元二十年（732）禁汉人信奉 |

**画法**：祆祠画圣火坛、祭司面罩；景教寺用十字＋莲花组合纹；摩尼教用"二宗三际"图式（明暗二色）。三者都**不要**画成佛寺形制。

## 四、民间信仰

| 神祇 | 职能 | 场所 |
|---|---|---|
| **社神** | 土地与农事，春祈秋报 | 社坛、社树；民间"社邑"结社 |
| **城隍** | 护城、司命、断讼 | 城隍庙（唐渐普及，B） |
| **灶神** | 家宅、饮食、上天言事 | 灶头 |
| **山神/河神** | 山岳、江河 | 山祠、河伯庙 |
| 土地 | 一方水土 | 土地庙 |
| 五道将军 | 冥界 | 墓侧、路旁 |
| 狐神 | 民间淫祀，唐人有"无狐魅不成村"之谚（B） | 村野 |

**画法**：民间小庙用一间土屋＋低矮神台＋红布；社树挂彩；不要画成规制完整的大庙。

## 五、节日

| 节日 | 时间 | 活动 | 视觉要点 |
|---|---|---|---|
| **元日（元旦）** | 正月初一 | 大朝会、拜年、饮屠苏酒、贴门神（桃符） | 宫门大开、百官朝服、爆竹（烧竹） |
| **上元（灯节）** | 正月十五，唐放三夜 | 张灯、观灯、踏歌、夜游，**弛夜禁** | 灯轮、灯树、仕女夜行；最华丽的夜景 |
| **寒食** | 冬至后一百五日 | **禁火三日**、冷食、扫墓、蹴鞠、秋千、拔河 | 冷食（馓子、子推饼）、纸钱、秋千架 |
| **清明** | 寒食后 | 扫墓、踏青、插柳 | 新绿、柳枝、纸鸢 |
| **端午** | 五月初五 | **竞渡**、角黍（粽子）、艾、菖蒲、五色缕、赠扇 | 龙舟、彩缕、艾虎 |
| **七夕** | 七月初七 | **乞巧**（穿针、蛛丝）、曝衣、拜织女 | 月下庭院、彩楼、蛛网 |
| **中元** | 七月十五 | 盂兰盆会、放灯、祭祖 | 河灯、佛事 |
| **中秋** | 八月十五 | **赏月**（唐中期始成俗）、玩月、宴饮 | 月、桂花、酒；**月饼无** |
| **重阳** | 九月初九 | 登高、插茱萸、饮菊酒、赏菊 | 山亭、菊、茱萸囊 |
| **腊日** | 十二月初八 | 腊祭、腊八粥、赐口脂面药 | 灶火、粥锅、赐物 |
| **除夕** | 岁末 | **驱傩**（戴面具、击鼓）、守岁、爆竹 | 傩面、火把、桃符 |

**注意**：上元"灯轮"为唐玄宗时长安所造，高约二十丈（B），是本作最值得做的夜景奇观。

## 六、庙会与市集

- **戏场**：长安戏场多设于寺院（如慈恩寺、青龙寺），演戏、说唱、百戏。
- **庙会**：佛诞（四月初八）行像、浴佛；东岳庙会、城隍出巡。
- **市集**：定期"草市"（城外）、"墟市"（南方）；庙会兼市集。

**画法**：庙会＝寺院山门＋幡幢＋摊位＋人潮＋戏台。摊位用布棚，不要用明清式统一样式的红棚。

## 九、诗歌入乐

唐诗人诗多入乐歌唱。**旗亭画壁**故事（《集异记》）：王昌龄、高适、王之涣于旗亭饮酒，听伶人唱诗，各画壁记数。这是"诗歌—音乐—酒肆"三者交会的绝佳场景，可直接做成支线任务。

## 来源核验与时间一致性自检

1. 景教635年、摩尼教694年、祆教621年置祠，三者不可提前或混淆。
2. 中秋赏月可，月饼不可（宋代才有）。
3. 上元灯节三夜为唐制；隋代灯节规模较小，炀帝洛阳端门灯火属Ⅰ期特例（B）。
4. 梨园为玄宗所设，Ⅳ期前不得出现。
5. 会昌灭佛（845）超出本作下限，不得引用。
6. 俗讲、变文以敦煌文书为据，属Ⅲ—Ⅴ期。
7. 未编造书名卷次；网络引用仅列实际抓取成功页面。
