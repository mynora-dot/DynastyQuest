# 日常生活

> **核心结论**：隋唐城市生活被**"鼓—坊门—夜禁"**三件事切成昼夜两半。白天属于市与街，夜里属于坊内。货币是**钱帛并行**：铜钱记账，绢帛付大额。婚礼在**夜间**举行（"昏礼"），这是与后世最大的习俗差异之一。
>

## 一、一日作息：晨钟暮鼓

| 时刻 | 事件 | 依据 |
|---|---|---|
| 五更（约3—5时） | 宫中击鼓，诸街鼓承振，**坊门、市门开启** | 唐长安街鼓制度（B） |
| 破晓 | 坊内人外出，街上有行人、驴马、水车 | — |
| 日中（午时） | **击鼓三百声开市**，市门启 | 《唐六典》卷二十（A/B） |
| 日入前七刻 | **击钲三百声散市**，市门闭 | 《唐六典》卷二十（A/B） |
| 日暮 | 击鼓**八百声**，**坊门关闭** | 唐长安街鼓制度（B） |

| 夜间 | 坊内可活动，坊外街衢禁行；巡夜武侯铺 | — |

| 项目 | 内容 |
|---|---|

## 三、货币

| 货币 | 时间 | 说明 |
|---|---|---|
| 隋五铢 | Ⅰ期 | 隋文帝铸五铢，整顿私铸 |
| **开元通宝** | **武德四年（621）始铸** | 废五铢，钱文"开元通宝"，径约2.4厘米、重约4克（B）；"开元"意为"开新纪元"，非年号 |

**物价（B，仅作游戏参考）**：开元天宝间长安米一斗约十余至二十文；一匹绢约二百文上下；一头牛数匹绢。**不要给出精确到文的固定价目表**，各年波动极大。

**画法**：铜钱方孔圆钱，锈色青绿；绢帛卷成"匹"状，用红绳捆扎。交易时钱帛都要出现。

## 四、购物讲价

唐市无明码标价传统，牙人（中介）居中撮合。常见话术："直多少？""减些。""依你。"大额交易请牙人、立券、付"牙钱"。**游戏可做"三寸不烂之舌"讲价小游戏**：出价—还价—成交/翻脸三段。

## 五、饮食起居

- 席地而坐（跪坐）为主，**高足家具在唐中期后渐多**，但椅子尚未普及；坐具为筵、席、胡床（折叠凳）、绳床。
- 食案矮小，一人一案分食。
- 卧具：床、榻，设帐；富贵用屏风。
- 照明：油灯（动物脂、植物油）、蜡烛（贵）；灯台多陶、瓷、三彩。
- 卫生：洗漱用"澡豆"；厕所有溺器（虎子/马子）。
- 取暖：炭盆、手炉；**火炕尚未普及**（C）。

## 六、婚丧

### 6.1 婚礼：六礼与夜婚

| 步骤 | 内容 |
|---|---|
| 纳采 | 男方请媒通言，送雁 |
| 问名 | 问女方姓名、生辰 |
| 纳吉 | 占卜得吉，定婚 |
| 纳征 | 送聘礼（绢帛、金银、食物） |
| 请期 | 定婚期 |
| **亲迎** | 新郎到女家迎娶，**在黄昏后**举行 |

**夜婚细节**：青庐（临时帐幕）交拜、合卺（剖匏为二，各执一瓢饮酒）、**却扇**（新娘以扇遮面，新郎赋诗却扇）、**障车**（女方亲友拦车索要财物）、撒帐。婚礼用**青、红**，不用后世大红盖头（盖头普及较晚，B）。

### 6.2 丧葬

停尸→招魂→小敛→大敛→殡→出殡→下葬→服丧。唐制服丧：斩衰三年、齐衰、大功、小功、缌麻。墓室形制：土洞墓（平民）、砖室墓（官员）、壁画墓（贵族）；随葬俑、明器、墓志。

## 十一、社会阶层

| 层级 | 构成 | 特征 |
|---|---|---|
| **良人** | 士、农、工、商 | 有户籍，可应举、授田 |
| 士 | 官员、读书人 | 免课役，服色按品 |
| 农 | 均田农民 | 租庸调，服徭役 |
| 工 | 匠户 | 番役，不得入仕（制度上） |
| 商 | 市籍 | "工商不得预于士"，服色受限 |
| **贱民** | 部曲、奴婢、官户、杂户 | 部曲为私属，奴婢同资产；官户隶属官府；**良贱不婚**（《唐律》） |

**流动性**：科举、军功、恩荫是上升通道；安史之乱后人口流动加剧，坊市制松动。

## 十二、女性生活

- **参政**：武则天称帝（690—705）为顶点；上官婉儿掌制诰。
- **社交**：女性可出游、骑马、打球、结社（"女人社"见于敦煌文书）。
- **婚姻**：有"和离"（协议离婚）文书；再嫁常见，礼法非绝对。
- **财产**：嫁妆为女方私产，有一定支配权。
- **职业**：胡姬当垆、女医、女尼、女冠、织女、歌妓。

---

## 十三、胡汉杂处

长安西市是"胡化"最集中的空间：波斯邸、胡姬酒肆、胡饼店、珠宝行、香药行。胡人着翻领袍、尖帽，用银币（波斯银币在唐境内有出土，B）。洛阳、扬州、广州同样胡商云集。**画法**：西市场景中每5—8人安排1个胡人，招牌可加粟特文/波斯文点缀（不必可读）。

## 来源核验与时间一致性自检

1. 开元通宝621年始铸，隋代场景只能用五铢。
2. 夜市在Ⅰ—Ⅲ期属违禁，不得作为常规场景。
3. 婚礼在夜间，用青庐、却扇，不用红盖头。
4. 中秋赏月可，月饼不可。
5. 椅子、高桌在Ⅲ期前应慎用，以矮案、席地为主。
6. 良贱不婚为法律原则，剧情跨阶层婚姻需设置冲突。
7. 物价只给区间，不给精确数字。
