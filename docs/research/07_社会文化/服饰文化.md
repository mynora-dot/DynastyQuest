# 服饰文化

> **核心结论**：隋唐服饰的最大变量是**"品色衣"制度的建立与细化**，而它的时间点常被说错。准确链条是：**隋代无严格品色制**（天子与贵臣通服赭黄袍、乌纱帽、折上巾、六合靴）→ **武德四年（621）**始著衣服之令，初分紫、朱、黄、绿、青 → **贞观四年（630）八月**诏"三品以上服紫，五品以上服绯，六品七品以绿，八品九品以青" → **龙朔二年（662）**八九品改碧 → **上元元年（674）**细化为深绯/浅绯、深绿/浅绿、深青/浅青并配带銙。因此"品色衣定型于高宗前后"只说对了一半：**框架定于太宗贞观四年，等级细化定于高宗上元元年**。
>
> 可信度标记：A 可靠 / B 细节有争议 / C 学界异说 / D 游戏推演。

## 一、制度：品色衣的四个节点

| 年代 | 内容 | 级别 |
|---|---|---|
| 隋 | 隋文帝听朝之服：**赭黄文绫袍、乌纱帽、折上巾、六合靴**，"与贵臣通服"；唯天子之带有十三镮；"百官常服同于庶人" | A（《新唐书·车服志》） |
| 621（武德四年） | 始著衣服之令，"上得兼下，下不得拟上"。亲王及三品、二王后服大科绫罗，色用紫；五品以上小科绫罗，色用朱；六品以上色用黄；六七品绿；八九品青；流外、庶人、部曲、奴婢服绸绢絁布，色用黄白 | A |
| **630（贞观四年八月丙午）** | **诏：三品以上服紫，五品以上服绯，六品七品以绿，八品九品以青；妇人从夫色** | A（《旧唐书·太宗纪》《册府元龟》） |
| 662（龙朔二年） | 八品九品旧著青，"深青乱紫，非卑品所服"，改著**碧**；朝参处不得著黄 | A |
| **674（上元元年）** | 三品以上紫、金玉带；四品深绯、五品浅绯，并金带；六品深绿、七品浅绿，并银带；八品深青、九品浅青，鍮石带；庶人服黄、铜铁带 | A（《旧唐书·高宗纪》） |
| 684（光宅元年） | 武则天改旗尚白，外官服青者以碧 | A |
| 691（天授二年） | 佩鱼改**佩龟**；始许"借紫" | A |
| 694（延载元年） | 赐三品以上**绣袍**，各按职司绣纹：诸王盘石鹿、宰相凤池、尚书对雁、诸卫麒麟/虎/鹰/牛/豹/鹘/狮/豸 | A（《文献通考》） |
| 705（神龙元年） | 旗帜服色"并依永淳以前故事"，恢复旧制 | A |
| 714（开元二年） | 禁珠玉锦绣，已造锦绣衣物"听染为皂" | A |
| 737（开元二十五年） | 非有战功不得赏绯紫 | A |

**给美术的一句话**：紫、绯、绿、青是"官身"，黄白是"庶人"，皂（黑）多为仆役与丧服；**同一件圆领袍，换颜色就是换品级**——这是最省成本的角色差异化手段。

## 五、商人、平民

- **商人**：制度上"工商不得预于士"，服色受限，但富商逾制常见。画法：衣料用**暗纹绫罗**但颜色压在**绿、青、白**区间，配算袋、钱囊，避免绯紫。
- **平民男子**：**白衣**（本白，未染麻布）、短褐（粗麻短衣）、缚裤、麻鞋或草鞋；头裹皂巾或小幞头。
- **农夫**：短褐、露小腿、斗笠、腰系绳带；肤色偏黑。
- **部曲、奴婢**：服"绸绢絁布，色用黄白"，多为**本色麻布＋皂巾**，无佩饰。
- **妇女（平民）**：窄袖短襦＋长裙，裙腰高，颜色可用黄、白、碧，不得用绯紫大绫。

## 六、女性（分期最关键）

| 期 | 轮廓 | 领型 | 袖 | 裙 | 发髻 | 妆 |
|---|---|---|---|---|---|---|
| Ⅰ隋 | 修长、高腰 | 交领/直领 | 窄袖 | 高腰长裙，裙腰及胸下 | 平云髻、双鬟、盘桓髻 | 素净，少花钿 |
| Ⅱ唐初—贞观 | 纤细、上短下长 | 交领、圆领 | 窄袖 | 高腰/齐胸，条纹间裙 | 半翻髻、反绾髻、双环望仙髻 | 面靥初现，眉细 |
| Ⅲ高宗武周 | 渐丰 | 袒领（U形低领）出现 | 窄袖为主 | 齐胸长裙，帔帛绕臂 | 高髻、双鬟望仙 | 花钿、斜红开始流行 |
| Ⅳ开元天宝 | 丰腴、宽博 | 袒领、方领 | **宽袖渐大** | 齐胸裙、半臂、帔帛 | 倭堕髻、回鹘髻、义髻 | 花钿、面靥、斜红、樱桃小口齐全 |
| Ⅴ安史 | 由宽转实，胡服减少 | 收敛 | 宽袖 | 长裙 | 高髻简化 | 妆面转淡 |

**胡服**：翻领、窄袖、对襟、锦边，配**蹀躞带**与皮靴；Ⅳ期长安极盛，Ⅴ期因政治气氛收敛（B）。

**帔帛**：一条长2米以上的轻薄纱罗，搭肩绕臂垂落。**这是唐代女性最出效果的动态元素**，需要单独一层做飘动。

**半臂**：短袖外套，长及腰，套在襦外。

## 十一、首服：幞头演变

| 期 | 样式 | 特征 |
|---|---|---|
| Ⅰ隋 | 折上巾、平头小样巾 | 软裹，巾子低平，四脚软垂 |
| Ⅱ唐初 | 平头小样 | 顶平，脑后两脚下垂 |
| Ⅲ武周 | 高头巾子（武后赐百官） | 巾子加高，顶部圆鼓 |
| Ⅲ末—Ⅳ初 | 英王踣样巾（中宗赐） | 巾子高而前倾 |
| Ⅳ开元 | 内样巾子 | 顶部更圆，略前俯 |
| 晚唐以后 | 硬脚、展角 | **宋明乌纱帽展角不得用于本项目** |

**关键**：幞头两脚在隋唐是**软脚**（下垂或反系），不是宋代的平直硬翅。

## 来源核验与时间一致性自检

1. 隋代不得出现"品色衣九等"；隋文帝常服为赭黄袍＋乌纱帽＋折上巾＋六合靴（A）。
2. 贞观四年诏只分紫/绯/绿/青四色，**没有**深浅绯、深浅绿；深浅之分属674年。
3. 八品九品在630—662年间为"青"，662年后为"碧"，674年后为"深青/浅青"，三段时间不可混。
4. 佩鱼在691—705年为"龟"，705年复"鱼"。
5. 宋明乌纱帽展角、补子、立领、马面裙、马蹄袖一律不得出现。
6. 棉布不作为唐代中原平民主料。
7. 文中未编造书名卷次；网络引用均为实际抓取成功页面。
