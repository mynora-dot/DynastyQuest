# 饮食文化

> **核心结论（三条，必须贯彻）**
> 1. **隋代饮茶不普遍**。茶在隋及唐初是南方地方性饮料，北方士人少有饮用；要到**开元年间**因禅寺"学禅不寐、许其饮茶"而风行，**陆羽《茶经》成书约在780年前后**，此后才有"茶道大行"。**隋代场景里出现茶馆、点茶、茶博士，即为时代错误。**
> 2. **北方主食是粟，不是小麦面食**。麦作"饼"，唐中期以后面食地位才快速上升；含嘉仓出土刻铭砖记的正是"糙米""粟"。
> 3. **唐前期仍是两餐制**（朝食、夕食），三餐普及要更晚。
>

## 一、主食：粟、麦、稻

| 作物 | 地位 | 食用方式 | 期别 |
|---|---|---|---|
| **粟（小米）** | 北方第一主粮，赋税"租"以粟计 | 蒸饭、煮粥、酿酒 | 全程，Ⅰ—Ⅲ期绝对主导 |
| **麦** | 北方次主粮，唐中期后上升 | 磨面作**饼**；整粒作"麦饭" | Ⅱ期起面食增多，Ⅳ期大盛 |
| **稻** | 南方主粮，漕运北上 | 蒸饭、粥、酿酒 | 全程；含嘉仓刻铭砖载"苏州…糙米"（【考古】） |
| 菰米（雕胡） | 小众 | 雕胡饭 | Ⅰ—Ⅲ期 |
| 豆 | 副食兼救荒 | 豆饭、豆粥、豆酱 | 全程 |

【考古】含嘉仓刻铭砖（33×33×6厘米）记载仓窖位置、粮食品种（糙米/粟）、数量、纳粮时间与经手官吏，是唐代仓储制度最直接的实物。

### 1.1 饼类

| 饼 | 做法 | 特征 | 场景 |
|---|---|---|---|
| **胡饼** | 炉壁贴烤，面撒芝麻，可夹羊肉 | 圆、厚、表面焦黄带芝麻 | 市井、行旅第一主食；白居易有《寄胡饼与杨万州》 |
| **蒸饼** | 笼蒸发酵面团 | 白、软、圆 | 早餐、寺院 |
| **汤饼** | 水煮面片/面条 | 宽汤，可加葱、肉臊 | 冬日、病中 |
| **煎饼** | 鏊上摊薄 | 薄脆 | 寒食、旅途 |
| **馎饦** | 手揪面片入汤 | 不规则片状 | 北朝至唐通吃 |
| **毕罗** | 胡食，面皮包馅，或抓饭 | 有"蟹黄毕罗"（《酉阳杂俎》） | Ⅳ期长安胡食店 |
| **冷淘** | 过水凉面 | 夏日，槐叶冷淘为青色 | Ⅳ期，杜甫诗咏 |

### 1.2 饭与粥

粟饭（黄）、稻米饭（白）、麦饭（粗）、雕胡饭。粥有粟粥、米粥、豆粥、**长生粥**（烧尾宴菜名）。贫家以菜混米煮"菜饭"。

## 二、副食

### 2.1 蔬菜

葵（冬苋菜，唐第一常蔬）、韭、薤、菘（白菜类）、蔓菁、萝卜、茄子、黄瓜、藕、笋、莴苣、**菠菜**（尼波罗国传入，唐初，B）、**莙荙**（甜菜）。野菜：荠、蕨、马齿苋。腌菜称"菹"，是过冬主菜。

### 2.2 肉

| 肉 | 地位 | 备注 |
|---|---|---|
| **羊** | 贵，宫廷与北方首选 | 烧尾宴多羊肉菜；"羊为贵"贯穿全程 |
| **牛** | **禁屠** | 牛为耕本，《唐律疏议》卷十五《厩库》故杀官私马牛者徒一年半（B）；民间私宰仍存 |
| **猪** | 平民肉食 | 价廉，南方更普遍 |
| **鸡/鹅/鸭** | 常见 | 鸡为最普通的待客肉 |
| **鱼** | 极重要 | **鱼脍**（生鱼片）为唐人名菜，切薄如丝，配芥酱、橙丝 |
| 鹿、兔、雉 | 野味 | 猎获、进贡 |

### 2.3 调味

盐（河东解池、江淮海盐）、酱（豆酱、肉酱）、豉、醋（米醋）、**胡椒**（西域进口，贵重）、**蔗糖/石蜜**（贞观二十一年遣使摩揭陀取熬糖法，B）、蜜、茱萸（辣椒传入前的主要辛味）。**辣椒、土豆、玉米、番薯、番茄一律不得出现。**

## 三、酒

| 酒 | 说明 | 期别 |
|---|---|---|
| 米酒（浊酒/清酒） | 主流酒类；浊酒便宜、清酒贵 | 全程 |
| **葡萄酒** | 贞观十四年（640）平高昌得马乳葡萄种及酒法，种于苑中、自酿（B） | Ⅱ期末起 |
| **三勒浆** | 庵摩勒、诃梨勒、毗梨勒三果酿，波斯法 | Ⅲ—Ⅳ期长安流行 |
| 酪浆/酥 | 乳制品，胡食 | Ⅲ期起 |
| 蒸馏酒（烧酒） | 唐代是否已有蒸馏酒**存疑** | C，不采用 |

酒器：陶瓮、漆耳杯、金银碗（贵族）、**鹦鹉杯/叵罗**（胡器）。

## 四、茶（全篇最需强调的分期）

| 期 | 情况 | 级别 |
|---|---|---|
| Ⅰ隋 | 茶为南方（巴蜀、江淮）地方饮料，北方少见；隋文帝曾以饮茶为俭约话题，但**未成风俗** | A/B |
| Ⅱ唐初—贞观 | 仍属南方饮品，北方士人偶饮 | B |
| Ⅲ高宗武周 | 渐入北方寺院与士人圈，尚未普及 | B |
| **Ⅳ开元** | **《封氏闻见记》卷六："开元中，泰山灵岩寺有降魔师，大兴禅教。学禅务于不寐，又不夕食，皆许其饮茶……于是茶道大行，王公朝士无不饮者。"** | A |
| Ⅳ末—Ⅴ | 陆羽《茶经》约780年成书，煎茶法确立；建中元年（780）始征茶税 | A/B |

**唐式煎茶**：炙茶→碾罗成末→釜中煮水→加盐→投茶末→"三沸"→分酌。**不加葱、姜、枣、橘皮**（陆羽明确反对）。茶器：风炉、鍑、碾、罗合、则、碗。

**游戏里**：Ⅰ—Ⅲ期只能出现"茶粥/茗粥"式粗饮与南方茶摊；Ⅳ期才可出现茶肆、茶碗、茶碾。

## 五、点心与出土实例

【考古】吐鲁番阿斯塔那古墓群出土唐代食品一组，现藏新疆维吾尔自治区博物馆：

| 实物 | 形制 | 说明 |
|---|---|---|
| **饺子** | 小麦面，月牙形，皮薄有馅 | 唐代称"水角""角子""牢丸"；与今日饺子几乎无别 |
| 馄饨 | 面皮包馅 | 与饺子同出 |
| **花式点心** | 梅花式、菊花式、四棱式、四瓣/八瓣花纹 | 小麦粉捏制或模压，纹路清晰 |
| 面卷 | 卷制 | — |
| 馕 | 中心薄、边厚，中央戳花，撒芝麻 | 西域主食 |

"点心"一词即出现于唐代，宋人吴曾《能改斋漫录》称"自唐时已有此语"（B）。

## 六、宫廷宴：烧尾宴

【文献】景龙三年（709），韦巨源拜尚书左仆射，献"烧尾宴"于中宗。宋陶谷《清异录》录其食单，凡五十八品（B）。可用的菜名：

- **单笼金乳酥**、**曼陀样夹饼**、**巨胜奴**（芝麻面点）
- **御黄王母饭**（盖浇黄米饭）、**生进二十四气馄饨**（二十四样馅）
- **光明虾炙**、**丁子香淋脍**、**葱醋鸡**
- **遍地锦装鳖**、**缠花云梦肉**、**同心生结脯**
- **水晶龙凤糕**、**贵妃红**、**汤浴绣丸**

画法：烧尾宴场景用**矮案分食**（唐前期仍分餐），金银器、漆器并存，不用明清圆桌合餐。

## 七、百姓日常

- **两餐**：朝食（巳时前后）、夕食（申时前后）；体力劳动者加"小食"。
- 主食粟饭/麦饭，副食**菜羹＋盐菜＋酱**，肉极少（"七十者可以食肉"的余绪）。
- 炊具：陶甑、陶釜、铁锅（宋以后才普及炒菜，**唐以蒸、煮、烤、脍为主，炒菜少**）。
- 燃料：柴、炭；长安冬季缺薪，有"薪炭不给"之载（B）。

## 八、市场食品与胡食

- 长安东市、西市：酒肆（胡姬当垆）、胡饼店、毕罗店、鱼鲙摊、果子摊。

- **胡食清单**：胡饼、毕罗、搭纳、三勒浆、葡萄酒、酪、酥、胡椒、石蜜。

## 来源核验与时间一致性自检

1. **茶**：隋与唐初不得出现茶肆、点茶、茶艺表演；Ⅳ期才可大行。
2. **葡萄酒**：640年之前不得出现"唐土自酿葡萄酒"。
3. **三勒浆**：Ⅲ期前不写。
4. **烧尾宴**：709年，属Ⅲ期末（中宗），不得用于贞观或隋。
5. **饺子/点心**：实物属唐代（约7—8世纪），可用于Ⅲ—Ⅳ期，不宜用于隋。
6. 辣椒、玉米、番薯、土豆、番茄、花生（花生传入更晚，B）全部排除。
7. 炒菜不作为唐代日常烹饪方式。
8. 引用文献均到书名/篇名级，未编造卷次页码。
