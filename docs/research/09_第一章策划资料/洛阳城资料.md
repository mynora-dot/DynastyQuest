## 三、地理环境

- **河流**：洛水自西向东穿城；伊水在城南；谷水在城西；瀍水在城东。
- **山脉**：北邙山（城北）、龙门山（城南，伊阙）。
- **平原**：洛阳盆地，四面环山，号称"四塞之地"。
- **交通**：西通关中（崤函道），东通汴州（通济渠），北通黄河（孟津），南经伊阙通南阳、襄阳。
- **周边城市**：陕州（西）、汴州（东）、怀州（北）、汝州（南）。

**风水与军事**：北依邙山、南对伊阙、洛水穿城，既是形胜之地，也便于漕运。但盆地狭小，粮食依赖外部输入——这正是营建东都同时开通济渠的深层原因（B）。

## 四、城市布局（重点）

### 1. 总体形制

```
        ┌──────────────── 郭城（外郭城）────────────────┐
        │   ┌──────┐                                    │
        │   │宫城  │  圆璧城/曜仪城/含嘉城（东北）      │
        │   │紫微城│                                    │
        │   └──┬───┘                                    │
        │   ┌──┴───┐                                    │
        │   │皇城  │  官署区                            │
        │   │太微城│                                    │
        │   └──┬───┘                                    │
        │  ════╪════ 洛水 ═══════════════════════        │
        │   天津桥│                                       │
        │   ┌───┴──────────────┐                        │
        │   │  里坊区（洛南）  │  南市（丰都市）         │
        │   └──────────────────┘                        │
        └───────────────────────────────────────────────┘
```

### 2. 宫城（紫微城）

- 位于郭城西北隅，地势高，便于防守。
- 正门：**则天门**（唐改应天门）（B）。
- 正殿：**乾阳殿**（唐改乾元殿，武周改明堂）（A/B）。
- 其他殿：大业殿、徽猷殿、文成殿（B）。
- 宫城内设后宫、官署、库藏。

### 3. 皇城（太微城）

- 在宫城之南，是**中央官署区**：尚书省、门下省、内史省、九寺五监等。
- 正门：**端门**（B）。
- 与宫城以横街相隔。

### 4. 外郭城

- 夯土城墙，周长约 27 公里（考古推算，B）。
- 城门：南面数门，正南门隋名待考（唐名定鼎门，B）。
- 街道：棋盘格，主干道宽数十米至百米（天街宽约 100 米以上，B）。
- 里坊：约 100 余坊（隋 103 坊、唐 109 坊等异说，C）。
- 坊墙、坊门、十字街，实行**夜禁**。

### 5. 三市（隋）

| 市名 | 位置 | 规模 | 说明 |
|---|---|---|---|
| 丰都市（南市） | 洛水南 | "周八里，通门十二，一百二十行，三千余肆"（《大业杂记》，B） | 隋唐洛阳最大市场 |
| 大同市（西市） | 城西 | 规模较小 | 西域胡商聚集（B） |
| 通远市（北市） | 洛水北，临漕渠 | "二十里"（数字夸大，B） | 靠码头，货物集散 |

> **唐改**：唐改丰都市为南市、大同市为西市、通远市为北市。游戏在隋章应使用**丰都、大同、通远**旧名。

### 6. 水系与桥梁

- 洛水穿城，是城市命脉；
- **天津桥**：跨洛水，连接皇城端门与洛南里坊，是洛阳地标（A/B）；
- 城中渠道引洛水、谷水，供排水与运输；
- 西苑引谷、洛水，为通济渠起点（A）。

### 7. 仓储（隋代，务必用对）

| 仓名 | 位置 | 记载 | 级别 |
|---|---|---|---|
| 子罗仓 | 城内右掖门街西 | 《大业杂记》，约 60 窖（考古推测） | B |
| 回洛仓 | 城北 | "仓城周回十里，穿三百窖" | B |
| 洛口仓（兴洛仓） | 城东巩义 | "周回二十余里，穿三千窖" | B |
| ~~含嘉仓~~ | 含嘉城 | **唐贞观—永徽间始建，隋代不存在** | C |

### 8. 西苑（会通苑）

- 在城西，周二百里（《大业杂记》，B，数字或有夸大）；
- 内有海（人工湖）、蓬莱/方丈/瀛洲诸山、台观、十六院；
- 是通济渠的**渠首**："自西苑引谷、洛水达于河"（《隋书》卷三《炀帝纪上》，A）。
- 游戏价值：**皇家园林 + 工地**的反差场景。

## 五、城市经济

- **官营手工业**：将作监、少府监所属作坊，造舆服、器械、船舰；
- **商业**：三市，行会，邸店，胡商；

- **服务业**：酒肆、饼店、客栈、车马行；
- **农业**：城郊园圃、粟麦。

## 十、可用任务素材

1. **送图**：把修正后的渠线图送到西苑渠首（D，背景 A）。
2. **寻人**：寻找在工地失踪的师父（D）。
3. **对账**：子罗仓账目与实物不符（D，背景 B）。
4. **采买**：到丰都市买麻绳、桐油（D，背景 B）。
5. **偷梁换柱**：监工用劣质木桩，玩家调查（D）。
6. **桥头冲突**：南人商贩与北人军士争执（D，背景 B）。
7. **夜禁**：玩家被巡夜武侯抓住，需解释（D，制度 A）。
8. **胡商委托**：鉴定一颗宝石的真伪（D）。
9. **疫病**：工棚中出现病人，找郎中（D，背景 B）。
10. **逃夫**：一名民夫逃跑，玩家选择告发或放走（D，背景 B）。
11. **劝农**：城郊农人因征发误农时（D，背景 B）。
12. **佛事**：寺院施粥，玩家帮忙（D，背景 B）。

## 十一、历史知识卡片（示例 10 张）

1. **隋东都**：605 年，隋炀帝命宇文恺在汉魏洛阳城以西新建都城，即隋唐洛阳城。
2. **洛水穿城**：隋唐洛阳城以洛水为轴线，宫城在西北，皇城在南，里坊在东南。
3. **天津桥**：跨洛水的名桥，"天津"意为天河渡口。
4. **三市**：隋代洛阳有丰都、大同、通远三市，唐改称南市、西市、北市。
5. **里坊制**：居民区以坊墙围合，坊门晨开暮闭，实行夜禁。
6. **含嘉城**：605 年建，位于宫城东北，隋代是城，不是仓。
7. **含嘉仓**：唐贞观至永徽年间始建，隋代尚无（学界新说）。
8. **洛口仓**：隋代最大粮仓，号称三千窖，李密曾开仓赈民。
9. **西苑**：城西皇家园林，也是通济渠的渠首。
10. **则天门**：宫城正门，唐代改称应天门。
