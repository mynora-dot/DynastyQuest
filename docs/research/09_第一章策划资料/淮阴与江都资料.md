# 淮阴与江都资料

> 本章南段的两座关键城市：**楚州（淮阴/山阳）**是邗沟的北口，**江都（扬州）**是邗沟的南口与炀帝行都。
>
> 标记：A 可靠 / B 有争议 / C 异说 / D 游戏推演。

---

## 一、地名辨析（必须先讲清）

| 名称 | 性质 | 时代 | 今地 |
|---|---|---|---|
| 淮阴 | 县名 | 秦置淮阴县，历代沿用 | 江苏淮安淮阴区一带 |
| 山阳 | 县名/州治 | 隋置山阳县，为楚州治 | 江苏淮安淮安区 |
| 楚州 | 州名 | 隋开皇初置，大业初废，唐复置 | 治山阳 |
| 淮阴郡 | 郡名 | 唐天宝元年（742）改楚州为淮阴郡 | 治山阳 |
| 江都 | 县名/郡名 | 隋江都郡治江都县 | 江苏扬州 |
| 扬州 | 州名 | 隋扬州（大业改江都郡），唐扬州 | 治江都 |

> **常见错误**：把"淮阴"直接等同于"淮安市区"、把"江都"等同于"扬州全境"。正确说法是：**隋代楚州治山阳县（今淮安淮安区），淮阴是另一座县城；江都县是扬州州治所在。** 游戏中城市名与行政区名要分清。

## 二、楚州（山阳/淮阴）

### 1. 基本信息

| 项目 | 内容 |
|---|---|
| 隋代名称 | 楚州（治山阳） |
| 唐代名称 | 楚州；天宝改淮阴郡 |
| 今地 | 江苏省淮安市淮安区 |
| 行政地位 | 州治；邗沟北口 |
| 重要程度 | ★★★★☆ |
| 与运河关系 | 山阳渎（587）/邗沟（605）的北端起点 |

### 2. 地理环境

- **河流**：淮河（北）、邗沟（南）、射阳湖、白马湖。
- **地形**：江淮平原，水网密布，地势低洼。
- **交通**：北通泗州、南达江都；西通洪泽湖方向；东通海盐产区。
- **周边城市**：泗州（西北）、江都（南）、盐城（东）。

### 3. 城市与运河关系

- 邗沟自山阳南行，穿越射阳湖、樊梁湖等湖沼，至扬子入江（A）。
- 因湖面风浪与水位差，沿线设**堰埭**，船只需盘坝（B）。
- 楚州是**漕船换乘、修整、补给**之地。

### 4. 城市布局（D 复原）

```
        淮河
         │
   ┌─────┴─────┐
   │  楚州城    │  州衙、仓廪、民居
   └─────┬─────┘
         │
   ┌─────┴─────┐
   │  邗沟北口  │  堰埭、码头、船坞
   └─────┬─────┘
         │
      邗沟（南行）
```

### 5. 经济

- 漕运中转、造船、修船；
- 盐业（淮盐）；
- 渔业、稻米；
- 驿站、邸店。

### 6. 居民生活

- 船民、盐户、农民、工匠为主；
- 水神信仰（河伯、龙王）；
- 潮湿多雨，民居多为干栏/高台（C）。

### 7. 游戏场景

| 场景 | 玩法 |
|---|---|
| 邗沟北口 | 过堰、盘坝 |
| 船坞 | 修船、捻缝 |
| 盐场 | 晒盐、盐引 |
| 水神庙 | 祭祀、求签 |
| 湖面 | 风浪、操船 |

### 8. 任务素材

1. **过堰**：帮船主把粮船拖过堰埭（限时/协作）。
2. **修船**：找桐油、麻絮、木料（收集）。
3. **盐引**：盐商与盐吏的纠纷（调查）。
4. **风浪**：湖上遇险，救人（QTE）。
5. **水神祭**：祭祀仪式，寻找失踪的祭品（调查）。
6. **船工失踪**：夜里有人落水（调查）。

## 三、江都（扬州）

### 1. 基本信息

| 项目 | 内容 |
|---|---|
| 隋代名称 | 江都（江都郡治江都县）；扬州 |
| 唐代名称 | 扬州（天宝改广陵郡） |
| 今地 | 江苏省扬州市 |
| 行政地位 | 郡治/州治；炀帝行都 |
| 重要程度 | ★★★★★（第一章终点） |
| 与运河关系 | 邗沟南端，长江与运河交汇 |

### 2. 历史沿革

| 时期 | 事件 |
|---|---|
| 春秋 | 吴王夫差筑邗城，开邗沟（前 486） |
| 汉 | 广陵国 |
| 隋 | 置扬州，后改江都郡；炀帝建江都宫 |
| 605/610/616 | 炀帝三下江都（A） |
| 618 | 江都之变，炀帝被杀（A） |
| 唐 | 扬州大都督府，东南都会 |
| 唐后期 | "扬一益二"（C，时代需注意） |

### 3. 江都宫与迷楼

- **江都宫**：炀帝行宫，位于江都城内/蜀冈一带（C，具体位置有争议）。
- **迷楼**：相传为炀帝所建，曲折幽深（《大业杂记》等，B/C，可能有文学夸张）。
- **游戏处理**：可做富丽堂皇的行宫场景，但不要照搬后世园林布局；"迷楼"可作为解谜关卡（迷宫），标注为传说性建筑。

### 4. 城市布局

- 隋江都城在蜀冈一带，唐扬州城分为**子城（衙城）**与**罗城**（B）。
- 罗城为商业居民区，子城为官署。
- 运河穿城/绕城，码头繁忙。

### 5. 经济

- **盐**：江淮盐集散；
- **漕运**：南北货物中转；
- **珠宝、香料**：胡商；
- **造船**：唐代扬州是重要造船基地；
- **手工业**：铜镜、漆器、纺织。

### 6. 居民生活

- 富商、盐商、船户、妓女、僧侣、胡商；
- 夜市（唐后期更盛，隋代待考，C）；
- 园林、酒肆、茶肆（茶在唐中期后普及，隋代不普遍，C）。

### 7. 游戏场景

| 场景 | 玩法 |
|---|---|
| 江都宫 | 接驾、宫廷阴谋 |
| 码头 | 龙舟抵岸、卸货 |
| 盐市 | 盐商交易 |
| 胡商街 | 鉴定、交易 |
| 寺院 | 祈福、情报 |
| 长江渡口 | 渡江、风浪 |

### 8. 任务素材

1. **接驾**：龙舟抵达，玩家负责仪仗（流程任务）。
2. **宫廷密信**：送一封不能见光的信（潜行）。
3. **盐商失踪**：调查盐商被害（调查）。
4. **胡商鉴定**：辨别珠宝真伪（解谜）。
5. **渡江**：找船渡长江（交易/选择）。
6. **江都兵变**（618，超出本章时间，可作为尾声伏笔）。
