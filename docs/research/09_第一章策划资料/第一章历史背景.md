# 第一章历史背景：《隋朝·大运河》

> 本章是《隋唐行纪》的开篇。以下为策划用历史设定，**史实部分标 A/B，虚构部分标 D**。
>
> 本章时间窗：**隋大业元年（605）三月 — 大业二年（606）春**。核心舞台：洛阳 → 通济渠 → 汴州 → 宋州 → 泗州 → 邗沟 → 楚州 → 江都。

---

## 一、一句话概括

**大业元年，皇帝要在一年之内，把洛阳、一条新河、一座新都连成一体；而承担这一切的，是被征发的百万民夫。**

玩家不是皇帝，也不是将军，而是一个被卷进工程的普通人。他/她要在这条正在被挖出来的河边，活下去，并看清"盛世"的代价。

---

## 二、历史背景（A/B）

### 1. 政治局势

- 604 年，隋文帝崩，杨广即位（《隋书》卷三《炀帝纪上》，A）。
- 605 年三月，诏营东都洛阳，同时开通济渠、重开邗沟（同上，A）。
- 605 年八月，炀帝率庞大船队巡幸江都（同上，A）。
- 朝廷内部：杨素、宇文恺、虞世基等当权；高颎等老臣渐被疏远（B）。
- 地方：州县承担征发、转运、供给，压力巨大（B）。

### 2. 社会状况

- 大业初年，国家户口殷盛（《隋书》卷二四《食货志》称"户口益多"，B），但工程征发已使山东、河南民力紧张。
- 役夫来源：按郡县摊派，丁男不足则役及妇人（永济渠即有此记载，A）。
- 粮价、徭役、逃亡、疫病，是普通人最直接的压力（B）。

### 3. 工程进度（本章时间线）

| 时间 | 事件 | 玩家可见 |
|---|---|---|
| 605 年三月 | 诏营东都、开通济渠 | 洛阳城外工地全面开工 |
| 605 年春夏 | 通济渠施工 | 汴口引水、挖渠、筑堤、植柳 |
| 605 年夏 | 邗沟重开 | 楚州、江都段 |
| 605 年八月 | 炀帝幸江都 | 龙舟船队、沿途迎送 |
| 606 年春 | 东都大体建成 | 洛阳城初具规模 |

## 三、本章的核心矛盾（戏剧冲突）

| 矛盾 | 史实依据 | 游戏表现 |
|---|---|---|
| 皇权意志 vs 民力极限 | "发河南诸郡男女百余万"（A） | 工期倒计时、民夫死亡、逃亡 |

| 南北隔阂 vs 统一 | 灭陈仅 16 年，南北隔阂仍在（B） | 南人/北人 NPC 的偏见 |

## 六、玩家角色设定（D，虚构）

**建议设定**：主角是洛阳将作监下属的**年轻画工/水工学徒**（虚构），祖上为北齐工匠，因战乱入隋。懂一点测量与绘图，不通武艺。
- 优势：能看懂图纸、会打算盘、识字；
- 弱点：体力一般、身份低微、随时可能被征为役夫；
- 动机：寻找在工程中失踪的亲人/师父（虚构），并完成一次"送图"的任务。

> 这个设定让玩家可以**合法地出入工地、官署、码头、寺院**，也解释了为什么 NPC 愿意与玩家说话。

## 八、本章要传达的历史认识（知识目标）

1. 大运河**不是一个人一拍脑袋挖出来的**，而是分五期、利用旧道、逐步整合的工程；
2. 工程的技术核心是**测量、土方、堤防、堰埭**，不是"神奇机械"；
3. 运河的代价由**普通民夫**承担，这是理解隋亡的关键；
4. 运河也带来了**城市、商业、南北交流**，不能只讲苦难不讲建设；
5. 历史评价是复杂的：**同一件事，皇帝看到功业，民夫看到坟墓**。
