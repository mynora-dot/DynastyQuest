# 运河工地资料（605 年通济渠工地）

> 第一章的核心场景类型：**工地**。本文件把"百万民夫修运河"从一句史书数字，拆成可玩的空间、人物、日程与冲突。
>
> 标记：A 可靠 / B 有争议 / C 异说 / D 游戏推演。

## 一、工地的空间结构

一个典型的通济渠工段（D，据水利史通识复原）：

```
        黄河/水源
           │
      ┌────┴────┐
      │  引水口  │  闸口、水尺、看守棚
      └────┬────┘
           │
   ════════╪══════════  已开挖渠段（有水）
           │
   ┌───────┴────────┐
   │   开挖工作面    │  分层取土、运土坡道
   └───────┬────────┘
           │
   ┌───────┴────────┐
   │   堆土区/堤身   │  夯土、木桩
   └───────┬────────┘
           │
   ┌───────┴────────┐
   │  工棚/伙房/医棚 │  草棚、灶、水缸
   └───────┬────────┘
           │
   ┌───────┴────────┐
   │  监工所/料场    │  工具、绳索、粮食
   └────────────────┘
```

### 分区与玩法

| 分区 | 视觉 | 玩法 |
|---|---|---|
| 引水口 | 木闸、水尺、浑浊河水 | 水位解谜、闸门启闭 |
| 开挖面 | 黄土阶梯、绳梯、箩筐 | 挖掘、搬运、塌方救援 |
| 堤身 | 夯土、木桩、夯歌 | 夯土节奏小游戏、验堤 |
| 工棚 | 草棚、通铺、灶烟 | 对话、休息、偷听 |
| 伙房 | 大锅、陶碗、粟饭 | 分粮、克扣、下毒事件 |
| 医棚 | 草药、病患 | 疫病、救治 |
| 监工所 | 木案、竹简、鞭子 | 领任务、对账、冲突 |
| 料场 | 木料、麻绳、铁器 | 偷料、验料 |

## 二、一天的作息（D，据劳役通识）

| 时辰 | 活动 | 声音 |
|---|---|---|
| 寅时（约 4—5 点） | 鼓/锣起床，点名 | 梆子、呵斥 |
| 卯时（5—7 点） | 上工，领工具 | 铁器碰撞 |
| 辰—午（7—13 点） | 挖掘、挑土、夯土 | 夯歌、号子 |
| 午时（11—13 点） | 吃饭、短暂休息 | 碗筷、抱怨 |
| 未—申（13—17 点） | 继续施工 | 号子、鞭响 |
| 酉时（17—19 点） | 收工、点名、还工具 | 疲惫的脚步声 |
| 戌时（19—21 点） | 吃饭、睡觉 | 鼾声、咳嗽、低语 |
| 夜间 | 巡夜、防逃 | 更鼓、犬吠 |

**关键细节**：
- 民夫自带或由官府供给口粮，常不足（B）；
- 冬季施工少，春夏为高峰期（B）；
- 雨天停工，但工期不延（D）；
- 病、伤、逃，是监工最头疼的三件事（B）。

## 五、工地社会：五类人

### 1. 民夫（D）
- 来源：河南、淮北诸郡征发；
- 心态：想活命、想回家、想少干活；
- 话题：口粮、家乡、逃不逃、工头好坏。

### 2. 监工（D）
- 来源：州县差役、军队小校；
- 压力：工期、上头催逼；
- 两难：打人则民怨，不打则误期。

### 3. 水工/匠人（D）
- 技术骨干，待遇稍好；
- 骄傲、保守、看不起"泥腿子"；
- 掌握关键知识（测量、闸门）。

### 4. 商人（D）
- 卖酒、卖饼、卖草鞋、放贷；
- 与监工勾结，克扣口粮；
- 情报灵通。

### 5. 女性（B/D）
- 丁男不足时被征（永济渠"始役妇人"，A）；
- 做饭、缝补、照顾病患；
- 也可能逃亡、被欺辱。

## 八、工地声音与氛围（音频/文本）

- **号子**："嗨——哟——"的夯歌，一人领、众人和；
- **夯声**：沉闷、有节奏；
- **水声**：渠水拍岸；
- **鞭声**：监工的威胁；
- **咳嗽**：肺病、尘肺；
- **哭声**：死人、想家；
- **风声**：旷野、堤上。

> 游戏中可用**音效 + 短文本**营造，不必做全程配音。
