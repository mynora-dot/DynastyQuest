# 隋唐世界地图节点

> 本文件说明 `11_地图数据/` 下四份 JSON 的字段、用法与限制，并给出可直接用于游戏世界地图的节点分区表。
>
> 配套文件：
> - `隋唐城市位置数据.json`：城市/关隘/遗址节点
> - `隋唐交通路线.json`：驿路、水路、栈道、海路
> - `大运河路线数据.json`：五段运河的河段、方向、连接关系与折线
> - `历史地名映射.json`：隋名/唐名/今地对照

---

## 一、字段规范

### 城市节点（`nodes[]`）

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 唯一标识，小写英文+下划线 |
| `historical_name` | string | 历史名称，多名称用"／"分隔 |
| `aliases` | string[] | 别名、异称 |
| `dynasty` | string | 适用朝代（隋／唐／隋—唐） |
| `modern_name` | string | 今地 |
| `latitude` / `longitude` | number | WGS84 十进制度 |
| `location_description` | string | 位置说明，含"大致方位"提示 |
| `historical_importance` | string | 历史地位 |
| `related_events` | string[] | 相关事件 |
| `confidence` | "A"/"B"/"C"/"D" | 可信度 |
| `source` | string | 出处 |

### 交通路线（`routes[]`）

| 字段 | 说明 |
|---|---|
| `id` | 唯一标识 |
| `start_location` / `end_location` | 起止节点名 |
| `route_name` | 路线名 |
| `dynasty` | 适用朝代 |
| `route_type` | 驿路／水路／栈道／海路 |
| `intermediate_locations` | 中间节点（有序） |
| `historical_function` | 历史功能 |
| `historical_period` | 通行年代 |
| `length_li_estimate` | 里程约数（里） |
| `confidence` / `source` | 可信度与出处 |

### 运河河段（`segments[]`）

除上述字段外，另加：
- `engineering_type`：**新开／疏浚／利用旧道／混合**（这是区分史实的关键字段）
- `direction`：走向
- `via_nodes`：带经纬度的折线节点
- `connects_rivers` / `connects_cities`

---

## 二、坐标使用规则（重要）

1. **坐标为今地坐标，不是古城址坐标。** 古城址往往与今城区相差数公里，个别（如泗州）已没入水下。
2. `confidence` 为 B 的节点，误差可能在数公里量级；C 级仅作示意。
3. **不要把经纬度直接当作"历史地理精确复原"**；游戏地图应按比例缩放，并做美术化处理。
4. 若后续接入真实 GIS 数据，应以考古报告与《中国历史地图集》为准，替换本文件的近似值。
5. 所有坐标均未编造，取今城区/遗址保护区中心；凡不确定者已在 `location_description` 注明。

## 四、地图比例与游戏化建议

| 项目 | 建议 |
|---|---|
| 世界地图比例 | 1 里 ≈ 1—2 像素（视屏幕而定） |
| 城市间距 | 按 `length_li_estimate` 缩放，勿平均分布 |
| 地形 | 关中盆地、黄淮平原、江淮水网、河北平原、河西走廊、西域绿洲，六种主色 |
| 道路 | 驿路用虚线，水路用蓝色实线，栈道用锯齿线 |
| 关隘 | 山口图标，必须卡在通道上 |
| 运河 | 用 `via_nodes` 折线绘制，禁止拉直 |
| 迷雾 | 按章节解锁区域 |
