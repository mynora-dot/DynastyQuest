# 来源核验与历史时间一致性检查报告

> 本文件记录《隋唐行纪》历史资料库在交付前进行的**分专题核验**。核验分两项：
> 1. **来源核验**：每条重要结论是否有可追溯出处，出处是否被实际读到；
> 2. **时间一致性检查**：年代、人物生卒、制度分期、地名、称谓是否自相矛盾或时代错置。
>
> 核验日期：2026-11-08。核验方式：人工逐文件抽查 + 脚本扫描（关键词、断链、JSON 解析、字数）。

- 部分事件只知年月不知日 → 一律只写年月，不补日。

**结论**：通过。

### 专题 2：大运河

| 核验点 | 结论 | 依据 |
|---|---|---|
| 五段年份 | 一致 | 《隋书》《通鉴》 |
| 通济渠路线（西苑—板渚—汴州—宋州—泗州） | 与山东省水利厅《汴渠》条一致 | 政府网站，已实际访问 |
| 通济渠"广四十步" | 与《隋书》卷三一致 | 原文 |
| 永济渠"引沁水南达于河，北通涿郡" | 一致 | 《隋书》卷三；海委《永济渠》 |
| 江南河"八百余里，广十余丈" | 一致 | 《通鉴》卷一八一 |
| 广通渠"三百余里" | 一致 | 水利部水利百科 |
| 隋代无复闸 | 与技术史通说一致 | 标 C，未断言 |
| 含嘉仓 | **修正为唐仓** | 杨清越文（中国历史研究院网站，已实际访问） |

**发现的问题与处理**：
- 流行说法"隋炀帝开凿京杭大运河"与史实不符 → 全库统一改为"隋唐大运河，以洛阳为中心，人字形"。
- "含嘉仓是隋代粮仓"是常见错误 → 依据 2024 年研究改为唐贞观—永徽间始建，隋代用洛口仓、回洛仓、子罗仓，并在第一章资料中明确禁用含嘉仓。

**结论**：通过，含 1 处重要学术修正。
