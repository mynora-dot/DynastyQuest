# 《隋唐行纪》历史资料库

> 面向 2D 竖屏历史 RPG《隋唐行纪》（Cocos Creator 3.8 / 微信小游戏）的隋唐（581—763）历史研究资料库。
>
> **本资料库的第一原则：宁可标注"待考证"，也不编造。** 所有重要结论都尽可能给出来源；正史引至"卷—篇"一级；无法核实的细节统一进入《12_参考文献/待考证问题清单.md》。

---

## 一、这份资料库是什么

这不是一篇历史概述，而是一套**可以直接拆成地图、场景、NPC、任务、道具、对白、知识卡**的素材库。

- 时间范围：隋开皇元年（581）— 唐广德元年（763），共 183 年。
- 空间范围：关中、河南、江淮、河北、河东、河西、西域，兼及江南与蜀道。
- 内容维度：时间轴、大运河、历史地理、城市、人物、制度、社会文化、任务素材、第一章策划、知识图鉴、地图数据、参考文献。
- 使用对象：策划、编剧、美术、关卡、程序（地图数据）。

---

## 二、可信度体系（全库通用）

| 标记 | 含义 | 使用建议 |
|---|---|---|
| **A** | 正史本纪/志有明确记载，且可用第二部史书或考古材料互证 | 可直接作为剧情事实 |
| **B** | 有史料依据，但月日、数字或细节存在异说 | 可用于剧情，但避免在 UI 中断言精确数字 |
| **C** | 学界存在不同解释，暂不能确定 | 必须并列不同观点，或写成"传说/传闻" |
| **D** | 游戏设计推演或合理虚构，不属于确定史实 | 必须在设定集中注明"虚构" |

**同时遵守三条硬规则**：
1. 不把后世制度套到隋唐（尤其宋代复闸、明清漕运、晚唐使职）。
2. 不把传说当史实（如杨贵妃东渡、隋文帝被弑的细节）。
3. 不编造书名、作者、卷次、页码、网址、文物编号。

## 四、已经完成的研究

### 1. 时间基准（最重要）
- 《01_历史总览/隋唐历史时间轴.md》是全库**唯一基准**。所有文件的年代都必须与它一致。
- 包含：隋（581—618）、唐初（618—626）、贞观（627—649）、高宗武周（649—705）、中宗至玄宗初（705—713）、开元（713—741）、天宝（742—755）、安史之乱（755—763）八个阶段。
- 附"时间一致性校验规则"：人物不得提前出场、官职不得超前、地名随年代切换、年号不得混用、制度分期、战争起止。
- 附"存在争议的时间点"表（隋文帝死因、通济渠通航、含嘉仓年代、马嵬驿细节等）。

### 2. 大运河（第一章核心）
- 五段河道（广通渠 584、山阳渎 587、通济渠 605、邗沟 605、永济渠 608、江南河 610）逐段整理：开凿时间、主持者、起止、途经、连接河流与城市、运输功能、与其它河道关系、史料、争议。
- **明确区分"新开／疏浚／利用旧道"**，反对"一次性从零开凿"的流行误解。
- 工程技术与运输体系分隋、唐两栏，**明确隋代无复闸（船闸）**。
- 沿线城市（大兴、洛阳、汴州、宋州、泗州、楚州、扬州、涿郡）逐城整理，含游戏场景与任务建议。
- 运河人物：宇文恺、高颎、杨素、裴矩、苏威、虞世基、何稠、阎毗、李密、王世充、宇文化及、萧皇后等。
- 关键学术修正：**含嘉仓为唐仓（627—655 始建），隋代应为洛口仓、回洛仓、子罗仓**（杨清越说，C 级并注明争议）。

### 3. 历史地理与城市
- 隋代郡县、唐代道—州—县、都护府与羁縻府州。
- 主要河流、山脉、关隘、驿路、水路、栈道、海路。
- 古今地名对照（含易错项：汴州≠开封旧城、泗州已没入洪泽湖、瓜州城在锁阳城、涿郡=范阳同地异名）。
- 八座重点城市专档，每城含"十三节"结构（基本信息→布局→经济→生活→人物→事件→场景→任务→知识卡→争议→参考）。

### 4. 人物
- 六个时期的人物档案，统一字段：姓名/生卒/出身/官职/经历/关系/评价/遗迹/任务/出处。
- 生卒年不确定者一律标"待考证"，不补精确日期。
- 人物关系网络：家族、婚姻、僚属、敌对、师友五类。

### 5. 制度
- 三省六部、科举、均田、租庸调、货币商业、漕运仓储、府兵、募兵、节度使。
- 每项制度均分时代叙述，并给出"与普通百姓的关系"与"可转化任务"。
- 明确标注：两税法（780）超出主线；开元通宝（621）不是唐玄宗年号钱；节度使名号通行于 711 年后。

### 6. 社会文化与物质生活
- 建筑、服饰、饮食、交通工具、日常生活、宗教民俗、文物与生活用品。
- 重点服务 2D 美术：颜色、形制、材质、尺寸感、图层拆分、动画帧建议。
- 强调分期：隋、唐初、高宗武周、开元天宝、安史之乱五个时期的样式差异。

### 7. 游戏转化
- NPC 职业库（30+ 职业，含职责、收入、地位、对话主题、可发布任务）。
- 六类任务素材（寻物、送信、调查、收集、解谜、剧情），每任务十字段（背景/地点/人物/目标/流程/道具/操作/奖励/知识点/真实性）。
- 第一章 20 个任务（5 主线 + 15 支线）。
- 知识图鉴五类卡片，每张含解锁条件与插图建议。

### 8. 地图数据
- `隋唐城市位置数据.json`：40+ 节点，含经纬度与可信度。
- `隋唐交通路线.json`：20 条路线（驿路/水路/栈道/海路）。
- `大运河路线数据.json`：五段河段、方向、连接关系、折线节点。
- `历史地名映射.json`：80 组隋名/唐名/今地对照。
- 全部 JSON 已通过 `json.load` 校验，可被 TypeScript 读取。

## 九、维护规则

1. **改年代先改时间轴**：任何文件涉及年份，先改 `01_历史总览/隋唐历史时间轴.md`，再同步其它文件。
2. **新增结论必须带来源与可信度**，否则视为无效内容。
3. **发现冲突**：以正史本纪 + 《通鉴》干支为准；无法裁决者进"待考证"清单。
4. **虚构内容**：一律标 D，并在第一章/任务文档的"虚构与史实边界"表中登记。
5. **JSON 修改后**必须重新执行 `json.load` 校验。
6. **不要**把本资料库的内容直接当作游戏文案；文案需再做口语化与分级处理。
