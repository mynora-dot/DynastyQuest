# 隋唐探索关卡

## 从资料到关卡

1. 确定本段故事的年代、地点和玩家目标。以时间轴校核地名、人物与制度，从资料库提取与玩家行动相关的史实，并为知识条目保留出处及可信度。 [历史资料库](../../docs/research/README.md)
2. 画出出生点、可交互点和出口的路线。对每个必经出口列出通行条件以及条件的取得位置。玩家漏看线索、提前拾取物品或重返地图时，仍应有办法完成必经任务。
3. 先打通一段最小流程。玩家从入口抵达 NPC，获得线索，完成一次拾取或机关交互，推进任务并解锁出口或图鉴。让图鉴说明玩家刚接触的地点、人物或做法。

## 实现与验证

- 地图、出口、NPC、任务、物品、机关和知识条目使用稳定 ID。用 ID 关联地图对象、对话条件及任务目标，避免把节点引用和显示名称写入存档。
- 使用 Tiled 时，将出生点、出口与交互点放入对象层，进入场景时检查目标 ID 和落点能否解析。单独验证障碍、角色遮挡与传送落点。 [Cocos 3.8 TiledMap 资源](https://docs.cocos.com/creator/3.8/manual/en/asset/tiledmap.html)
- 明确任务可接取、进行中、可交付和已完成时的行为。反复交互、重复触发出口或读档后再次检查完成条件时，已发放的奖励与已解锁的内容保持一致。
- 为场景机关写明可观察的线索、允许的操作、成功条件和必要的复位方式。分别验证错误尝试、完成后重进场景和复位后再解。
- 横屏试玩时检查地图移动与 UI 触控是否互相抢占，特别是对话、背包和机关面板开启时。用不同宽高比检查出入口提示、中文长句和操作区是否被裁切。 [Cocos 3.8 项目设置](https://docs.cocos.com/creator/3.8/manual/en/editor/project/)
- 在任务提交、关键拾取或章节切换后保存一致的进度快照。读取时校验版本和数据形状，区分首次启动与损坏存档，避免用空进度覆盖已有数据。验证退出重启后玩家位置、任务、机关和图鉴能一起恢复。 [Cocos 3.8 用户数据存储](https://docs.cocos.com/creator/3.8/manual/en/advanced-topics/data-storage.html)
